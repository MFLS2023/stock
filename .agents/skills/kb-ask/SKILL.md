# 知识库问答

**用户是因为不懂才问的。他要一个能听懂的答案，不是一堆待他自己解读的原文块。**

这个 skill 是知识库的默认入口。用户没指定要上课（`trading-knowledge-tutor`）、
没要求跨来源对比（`cross-source-synthesizer`）、没问实时数据
（`market-evidence-verifier`）时，都走这里。

---

## 工作流

### Step 1：查库

```bash
cd "C:\Users\20577\Documents\炒股\知识库"
python _知识库系统/scripts/query_kb.py "<用户的问题>" --limit 8 --expand
```

三件事必须做对：

- **整句直接丢进去**，不用自己拆关键词。整句无结果会自动按术语切词重试
- **`--expand` 必加**。用户的问法和作者的用词经常不一致：
  实测「情绪核心」库内 2 块，而作者们说「龙头」1825 块；
  「买卖计划」1 块，而他们说「推演」256 块
- **默认不限来源**。用户通常不知道是谁说的，让检索决定。
  只有用户明确点名某位作者时才加 `--source`

命中块读着像被截断，加 `--show-parent` 读完整父块 —— 答案常在相邻块。

来源 id 对照：`aizaibingchuan` 爱在冰川 / `fulibei` 复利杯 /
`tulip_garden` 郁金香花园 / `nanjinglu_bian` 南京路彼岸 / `panfeng` 我有上将潘凤

### Step 2：读，判断够不够答

- 命中的块**真的在回答这个问题**吗？还是只是含了那个词？
  （两字词走子串匹配，会捞到同形词。实测查「容量」会命中「脑容量不够」）
- 几个来源都讲了同一件事吗？**说法一致还是冲突**？
- 有没有明显的时间问题？（2017 年的说法未必适用现在）

### Step 3：答

**先给答案，再给支撑。** 结构是：

1. **一段话把答案说清楚**（这是用户唯一必读的部分）
2. **谁说的、怎么说的** —— 自然带出，如「复利杯的猴年古月讲得最直接：…」
3. **有分歧就摆出来** —— 这是本知识库比通用 AI 强的地方，不要抹平
4. **该说不知道就说不知道**

写法要求：

- **像说话，不像检索报告。** 不要输出 `[来源｜作者｜文档｜日期｜定位]` 这种元数据头
- **引原话时用引号，短句为宜**，长段落转述成自己的话
- **提到是谁说的就够了**，不必给 chunk_id。用户想深挖时再给
- **不要编号列表堆砌**。能用一段话讲完就别拆成五点

### Step 4：给一个下一步（一句话，不要每次都给）

按情况选一个，不合适就不给：

- 想学透这个概念 → 「要系统学的话可以用 `/trading-knowledge-tutor`，
  它会讲前提条件、失效情况，还能出练习」
- 几个作者说法冲突 → 「想看他们具体怎么分歧的，用 `/cross-source-synthesizer`」
- 问题涉及当下盘面 → 「这是他们的历史观点。要核今天的实际情况，
  用 `/market-evidence-verifier` 或直接查 live-market」
- 想用某个人的视角推演 → 「想听南京路本人怎么判断，用
  `/nanjinglu-bian-perspective`」

## 硬性规则

**查不到就说查不到。** 不要用通用交易知识补上去冒充作者观点。
正确说法：「这个问题我在库里没找到直接论述。库里相关的最接近的是…，
但那讲的是另一件事」。

**不要把不同作者的话混成一个人的观点。** 郁金香明确反对把情绪周期当分析框架
（「情绪周期是最事后观点的东西」），南京路认为它是「道的层面」的本质 ——
这两句话合并成一段就是造假。

**数字要说清出处。** 库里的量化阈值分三种：作者原文给的、整理方法卡时推的、
导师 SKILL 里 AI 补的。只有第一种能说成「他说」。

**历史观点标时间。** 2017 年和 2026 年的市场结构差别很大。
引用五年前的说法时带一句「这是 XX 年说的」。

## 已知的检索坑（会影响答案质量）

- **两字词会捞到同形词**：查「容量」命中「脑容量不够」。命中数很少时逐条读一眼
- **郁金香的「竞价」有大量错别字「竟价」**（129 块里 128 块在他这），
  `--expand` 会自动带上，但别忘了加这个参数
- **爱在冰川的「涨停动因」1354 块是同花顺栏目名**，不是他的概念，
  且那批小节正文 99.7% 为空（内容在图里）
- **爱在冰川的「川神」709 块全是读者叫他的**，不是自称
- **复利杯 42% 的块无法归因到具体嘉宾**（`author` 是「未从文件名明确识别」），
  这类只能说「复利杯的某位嘉宾」
- **图里的文字搜不到**。爱在冰川的行情截图未 OCR，但 3237 块能定位到图片文件，
  必要时可以打开看

## 一个好答案长什么样

用户问：**「怎么判断情绪周期到拐点了」**

❌ 不要这样：

> 根据知识库检索，共命中 8 条相关内容。
> [复利杯｜闻少｜1-［游资］「闻少」：竞业达周期的分析…｜2022-11-01｜第15页 32:33]
> 类型: transcript | 主题: 情绪周期、超预期…
> [32:33 发言人1] 你觉得这个情绪怪不怪？就是文具很简单…

✅ 这样：

> 库里几位作者的共同点是：**拐点不是算出来的，是等它出现后跟上去**。
>
> 复利杯的闻少讲得最直白 —— 他说抓拐点「其实说实话这个抓拐点只是运气，
> 更多的是运气」，真正该做的是「拐点出来以后，你要尽可能地去跟随这个拐点」。
> 他判断的依据是市场反馈和预期不一致：11 号情绪正常演变本该继续走弱，
> 12 号却反包了，那一天就是拐点。
>
> 南京路彼岸的角度不同，他看的是赚钱效应 —— 「情绪发酵来源于赚钱效应的打开，
> 情绪的崩溃来自模仿效应的泯灭」。所以他判断拐点看的是赚钱效应有没有重新打开。
>
> 两人都没给可以照着套的数字。要注意闻少那段是 2022 年说的。
>
> 想系统学这套判断，可以用 `/trading-knowledge-tutor`。
