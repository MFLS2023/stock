# 导师数字人试验

## 目的
验证"提炼导师数字人格"方案的可行性

## 试验对象
第一个导师：南京路彼岸

## 隔离原则
- ✅ 只读取 `../_知识库系统/indexes/knowledge.db`
- ❌ 不修改现有项目的任何文件
- ✅ 所有新产物放在 `_导师试验/` 目录
- ✅ 失败了可以直接删除整个目录

## 试验流程

### Phase 0：女娲生成（预计1周）
1. 提取南京路彼岸的所有文章
2. 用女娲skill生成第一版人格
3. 测试20-30个问题
4. 评估保真度

### 成功标准
- [ ] 回答立场和原文一致
- [ ] 能准确引用来源
- [ ] 人格特征明显
- [ ] 保真度评分 ≥ 70分（B级）

### 失败则
- 删除 `_导师试验/` 目录
- 回到原项目，不影响任何现有功能

### 成功则
- 保留试验结果
- 讨论如何整合到主项目
