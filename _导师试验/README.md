## 这个子项目在做什么

把知识库里的交易员资料，提炼成能对话的"数字导师人格"。

跟主知识库的分工：
- **主知识库**（`../`）回答"作者在某篇文章里说过什么"，是检索
- **本子项目**回答"如果拿这套体系看当前盘面，会怎么判断"，是推演

产物是 SKILL.md 文件（Agent Skills 协议），装进 Claude Code 后用 `/skill-name` 调用。

### `yujinxiang-wrong-approach` 错在哪（2026-08-08 补记）

| | 错误版 | 正式版 |
|---|---|---|
| 行数 | 434 | 1172 |
| 带来源标注的处数 | **1** | 11 |

**所以做导师 SKILL 的硬要求是：每条结论能回到 chunk_id，每个数字标明是原文还是推定。**

## 两个导师的核心差异

不是同一套方法论的两个版本，是两种不同的交易视角，**可以互相印证也可能冲突**。

| 维度 | 南京路彼岸 | 郁金香 |
|------|-----------|--------|
| 时间尺度 | 周期级（几周到几个月） | 日内级（9:20-9:30 定全天） |
| 核心工具 | 7 指标情绪量化 | 竞价体系 + 筹码断层 |
| 进场方式 | 等破局龙确认，不追高 | 卡位战法，9:20-9:25 抢先手 |
| 独创性最高的部分 | 天道压制、中周期龙护航 | 竞价体系、合力与做盘区分 |
| 最坦诚的失败案例 | 航天周期头铁巨亏 | 牛市卖飞、失眠 |
| 明确承认的短板 | 无法预测天道 | "牛市做不过新手" |
| 心智模型 | 7 个 | 7 个 |
| 决策启发式 | 12 条 | 15 条 |
| 反模式 | 15 条（已建立正反映射） | 15 条 |

**冲突点举例**：南京路的启发式 1 是"不追高，等回调或次日"，郁金香的卡位战法是
"9:20-9:25 提前挂单"。前者要等，后者要抢。这不是矛盾，是时间尺度不同——
但同时用两个 SKILL 时要清楚自己在用哪套。

## 关于第三个导师：爱在冰川

**结论：可以做，而且数据量最大，但有三个具体限制要先接受。**

### 有利条件

| 项 | 值 |
|---|---|
| 块数 | 5813（占全库 63.4%，是南京路的 11 倍） |
| 字符 | 4,094,344 |
| 时间跨度 | 2017-06 至 2026-08，**跨 10 年** |
| 作者 | 单作者，身份统一 |
| 方法论文章 | 616 块 `article` |
| 每日复盘 | 1653 块 `daily_review` |
| 每日数据 | 944 块 `daily_data` |
| 作者答问 | 2376 块 `qa_reply`（留言区本人回复） |

10 年跨度是南京路和郁金香都没有的——足够看出**思想演变**，
Phase 1 的"维度6：时间线"会比另两个导师扎实得多。
2376 块 `qa_reply` 是天然的"对话维度"素材，也比郁金香的 186 块飞书聊天丰富。

### 三个限制（必须先接受）

**限制1：图表内容全部不在库内**

公众号正文里大量行情截图、持仓截图，一律未 OCR。作者讲解常常是
"看图说话"，图没了，文字部分可能变成"如图所示，这里就是买点"这种空话。

影响：**技术形态类的心智模型会提不出来**，或者提出来是残缺的。
情绪周期、数据统计这类靠文字表达的部分不受影响。

**限制2：持仓被作者本人打码**

原文按"阅读上 2w 就打马赛克"的惯例隐去证券名，**原文里就已经缺失**，
不是导入丢的。

影响：**决策链维度（Phase 1 维度5）会缺关键一环**——
能看到"我今天买了一只票，理由是……"，但看不到是哪只，
没法回溯验证这个决策后来对不对。南京路和郁金香的决策案例都有具体标的，
爱在冰川这部分会明显弱。

**限制3：`date` 是发布日不是交易日**

1855 篇可判定日期的文章里，1496 篇发布日与标题日期同日，323 篇发布日晚 1 天
（盘后复盘发在次日凌晨），还有 10 篇是作者把年份打错了。

影响：时间线维度要逐篇核对标题里的日期，不能直接用 `date` 字段。
工作量增加，但可解。

### 还有一个数据质量陷阱

`confidence` 字段在这个来源**基本无效**：正文 5764 块全部写死为 `high`，
不代表评估结果。只有额外资料那 49 块（36 medium + 13 low）是实标的。

拿 `confidence=high` 筛这个来源，等于把第三方汇编筛掉，
**筛不出"更可靠的正文"**。做提取时不能靠这个字段分优先级。

另外 9 篇"额外资料"里有 8 篇**不是作者本人写的**（读者摘录、他人整理），
`author` 字段已标明。提取时必须按 `author` 区分，
不能把股不南的摘录当成爱在冰川的原话。

### 建议做法

如果要做，**别照南京路的模式做**。南京路是"方法论文章为主"，
爱在冰川是"10 年日记为主"，素材性质不同：

1. **先做时间线**（维度6），这是它最强的维度，10 年演变能看出真东西
2. **主体用 `qa_reply` 做对话维度**（维度2），2376 块答问是它的独特资产
3. **心智模型从 616 块 `article` 里提**，`daily_review` 只作验证不作提取源
4. **明确放弃技术形态类模型**，图不在库内，硬提是编
5. **决策链维度降级处理**，标的打码，只能提"决策逻辑"不能提"决策案例"
6. **额外资料单独处理**，按 `author` 分开，摘录不能当原话

预计产出的 SKILL 会偏"复盘方法论 + 长期心态"，
而不是南京路那种"周期定位 + 龙头战法"，也不是郁金香那种"日内微观操作"。
三个导师的定位不重叠，这是好事。
