### 一、边界条件

**Q1 极端单边跌市里他的指标还有效吗**
- 作答：查 `指标失效 跌势` 直达 `[2026-03-21]下周展望321黎明在黑夜之后` 正文："这是2008年的下跌周线……**所有的指标,在这种跌势面前都失效了**。"可据此回答：极端跌势是他亲口承认的整套方法失效区。
- 判分：**⚠️**
- 失败机理：边界缺失（可查库补救）。SKILL 五个模型无一讲失效条件，指标表把 kdj_battle/position_line 当无条件工具列出；这次命中靠的是查询词碰巧含"失效"，换一种问法（"现在D值过80该跑吗"）SKILL 不会引导去查这个方向。

**Q2 牛市里还能用 KDJ 战法吗**
- 作答：查 `kdj战法 牛市` 直达两条铁证：`[2024-11-04]｜留言区第9条`"牛市中再运用kdj战法做反弹是不是不合适了?——**当然了,说了一万遍了**"；`[2023-07-07]下周展望77`"当出现那个过应信号以后,股指的企稳时间一般在4天左右……5月9日中午出现的信号,后面一般要调整32个交易日到54个交易日"。
- 判分：**⚠️**
- 失败机理：指标表无市场状态标注。答案查库可达且原话极硬，但 SKILL 模型5 表格把 kdj_battle 列为通用工具、零适用条件，加载者照表作答即错。

**Q3 "位置"指标的 16/80 是万能常数吗**
- 作答：查 `抄底逃顶 rsi 过80 破16` 命中 `[2025-11-01]十一月展望与策略`："**在震荡期间**,过80就是高点,破16就是低点……抄底准确率在百分百,逃顶准确率是80%"——限定语"在震荡期间"明确。另命中意外补充：`[2026-02-06]搬砖指南`"30分rsi不破16咋办,那你就换一个周期啊,15分,5分都可以"——周期可切换也是他明说的用法。[2021-05-10] 的"底下的绿线是15,有的股票是18"在 Q8 查询中亦命中。
- 判分：**⚠️**
- 失败机理：参数固定化误导。SKILL 写 position_line"6周期RSI变体，16抄底/80逃顶"无任何限定；(a) 震荡期限定 (b) 个股阈值要改 (c) 周期可换，三层限定全部未收录。

**Q4 KD 钝化算目标位的前提条件是什么**
- 作答：查 `钝化 目标位` 直达 `[2024-05-07]3219点的目标位是怎么来的`(paid) 全文：算法"涨了多少后面再涨多少"（2635→K过80涨292点→2927+292=3219；小目标3009+122=3131）；三条注意事项逐字在库："先确认钝化,钝化才有目标,没有钝化,就不能这样计算"/"25个交易日内出现了两次这样的钝化,小心第二次钝化的时候做顶"/"纯化确认时,股指要在55均线上方,在55线下方,一般就是顶部"；另有"成功率在85%左右""2015年我和向阳费时三周…完成"。

- 失败机理：算法与失效分支零承载。用户追问"钝化了目标多少"时 SKILL 无话可答，只能靠查库兜住；85% 自报成功率同时是 Q9 的素材。

### 四、引文真实性

**Q17 "除了李彪……"出处对吗**
- 作答：查 `李彪 缠论 大行情时间` 命中 `[2025-05-20]今年有没有三浪三｜留言区第6条作者回复`："除了李彪,我没见一个用缠论说对大行情时间的,没有时间的推论,等于没说。将来肯定突破3674啊,不是100%,是10000%,这种结论有个毛用???"——前半句逐字吻合、日期文章名正确。
- 判分：**✅**
- 小瑕疵（题集指出、本次结构上确认）：后半句"有时间,不知道具体空间……忽悠人的"在同篇第7条（另一条回复），SKILL 把相邻两条回复合并成一条引文且未分开标注条位。

**Q18 图内例子"3949 已破 3936 是第一道防线"是真的吗**
- 作答：查 `3936 防线` 三处命中同一句话：chart_ocr 两处（boduanzhimen-wx-818fe5c5c4f3 / boduanzhimen-wx-e1461445c068）+ **留言区作者回复一处**（boduanzhimen-wx-20664d4afc28-p002-c01，文本层干净），原文均为"**3949已破,3936是第二道防线**,这个再破,后面就有点深了"。SKILL 写成了"第一道防线"——确证失真。
- 判分：**❌**（全场唯一引文硬伤，且发生在 SKILL 教人防 OCR 错误的示范例里）
- 失败机理：引文失真。加载者若直接复述 SKILL 内置例子（它以"已核实"姿态出现，AI 极少对示范例回查）就输出错误信息。附带发现让问题更深一层：这句话在留言区文本层也存在，"图内文字是独家信息"的论证在此例上双重不成立。
