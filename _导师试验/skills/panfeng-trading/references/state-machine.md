# 环境状态机

体系中枢。状态标定错误 → 后续所有操作无效。

## 四态判据表

逐项核验，命中 3 项以上判定该状态成立。带 ★ 的必须靠当日实时数据。

| # | 判据 | 主升期 | 顶部区 | 退潮期 | 数据来源 |
|---|---|---|---|---|---|
| 1 | 打板时心里在算什么 | 算能赚几个点 | 两者都算 | 算不会亏多少 | 用户自述 |
| 2 | ★打板位置 vs 上月 | 相近或更高 | 开始下移 | 下移 30%+ | 涨停板数据 |
| 3 | ★昨日强势股今日溢价 | 有 | 缩小 | 无 | 昨涨停股今日表现 |
| 4 | ★逻辑票今天给不给弹性 | 给 | 偶尔给 | 不给 | 主线个股涨跌 |
| 5 | ★强势股是否补跌 | 否 | 少数开始 | 全面补跌 | 前期龙头走势 |
| 6 | ★轮动速度 | 有序 | 加快 | 早涨午跌、无序 | 板块日内表现 |
| 7 | 上一笔试错是否赚钱 | 是 | 不稳定 | 否 | state 文件 |

判据 1 是最好用的一条，原话：

> "上个月打个板就开始算明天能赚几个点，这个月每次打板都要算不会亏多少。而且这个月打板的位置都比上个月低 30%。"

## 补充判据

**补跌进度条**——把补跌当完成度看，不是当利空看：
> "昨天所有强势的票，全部都在补跌，包括看好的端侧、光。这地方科技已经滚刀肉了。"
> "华虹公司这些相对指数还没补跌。"

有票没补跌 = 没跌完。全面补跌 = 退潮进入中段。

**估值标尺切换**（判断"跌够没有"的核心工具）：
> "之前很多科技股是按照明年业绩估值的，所以目前依然没有杀透。因为之前环境好按明年估值，现在股灾了，大家会用放大镜，按照今年估值。"

环境切换时估值基准从"明年"退回"今年"，跌幅远超按打折思维的直觉。用当年 EPS 重算，不是给去年估值打个折。

**极端读数**：
> "东山精密的双跌停……已经比科技最悲观的人的预期走的还差了。"

走势超过最悲观者预期 → 已非定价问题，是流动性问题 → 进入超跌节点候选。

**退潮期定性特征**（三条，用于确认自己在退潮期）：
> "一个突发的小题材，昨天最赚钱的，然后小票一字上去，参与到了就是大分歧，或者亏钱，你根本参与不到，没啥本质区别。"
> "退潮期你根本没办法重仓。只要你重仓，一定先洗你十几cm，然后拉起来，好的红盘卖，卖的不好水下卖。"
> "只要你敢出手，就一定是被套。"

## 四套参数集

### A 主升期

| 参数 | 值 |
|---|---|
| 单笔上限 | 可较重但不满仓（留弹药） |
| 出手频率 | 常态，看节点 |
| 持有久期 | 数日至趋势，须有一周内催化剂 |
| 逻辑作用 | **进攻**——给股价弹性 |
| 卖出 | 以卖飞为主，坚决止损 |
| 主要动作 | 找逻辑、埋伏、卡点 |

主升期反直觉警告：
> "我们还是熊市的经验太丰富了，所以说牛市做不过新手，老手天天切换。"
> "新股民又不会研究基本面，又不会研究心得，就一直拿着。"
> "新手刚入市就碰到牛市，绝对不是好事。"

技能在错误环境里是负债：纪律在主升期是收益漏损，耐心在退潮期是致命伤。

同时："科技这地方赚钱还是要以卖飞为主。这种科技牛市最后一定有一次回不来了。所以不要养成持股的习惯。"

### B 顶部区

| 参数 | 值 |
|---|---|
| 动作 | 只减不加，边打边撤 |
| 减仓顺序 | **先卖逻辑差的，后卖逻辑好的** |
| 持有久期 | 大幅缩短 |
| 逻辑作用 | **排序**——决定谁后跌 |
| 新票 | 仅位置极低时小仓 |

> "这边大概率逻辑差的会先下去，然后最后是逻辑好的。这边不会立刻马上下去，因为牛市。但是大家会边打边撤，和我思路差不多。去伪存真就是最后几个会出业绩的。"

他自己承认的边界："但是你们的信息渠道应该也验证不出来谁最后真的出业绩、谁假的出业绩。"

不走极端：
> "我觉得不要极端。就像我，虽然海外卖了，但也没有完全空仓。就是因为这边撤退慢慢撤，没必要要不然梭哈、要不然就空仓。"

### C 退潮期 / 股灾（当前语料的主要场景）

| 参数 | 值 |
|---|---|
| 单笔上限 | **一成** |
| 出手频率 | **隔天最多一次** |
| 持有久期 | **隔日，次日必走** |
| 逻辑作用 | **只做负筛选**，不做下注依据 |
| 选股 | 只看强度不看逻辑；位置最极端 或 有大资金护持 |
| 失败处理 | 不开第二枪，停手到下个节点 |
| 月度上限 | 最多三成（三次一成） |
| 头号禁令 | 不缠打 |

原话集：
> "现在的策略每隔一天最多一成试一次，不行就继续休息。"
> "你们只要看自己手里试错的仓位不赚钱，那么就绝对不开第二枪。"
> "这行情如果一次出手不行，不要叠加任何二次出手。这是当下行情最基本的风控。"
> "按照熊市的做法，一个节点只有一次机会。"
> "后面一个月最多就一成试错。""三成是很看得起市场了。"

久期压缩理由：
> "现在只要你持股，就是最大问题，最大亏损来源。最好的交易就是隔日。"
> "不要去判断趋势，因为买了你也拿不住了。所以就是隔日判断就行了。买强的，无论亏钱赚钱，第二天也就走了，不会缠打。这个地方缠打是个很危险的举动。"
> "这地方不看逻辑，只看强度，只要一夜情。"

选股二元收敛：
> "因为现在退潮期，所以要不然买位置低的，要不然买长鑫科技这种核心。"

### D 修复节点（退潮中的特殊窗口）

| 参数 | 值 |
|---|---|
| 仓位 | 一成 |
| 触发 | 极端超跌 + 大资金现身 |
| 持有 | 隔日，赚钱也不延长 |
| 成功后 | 不立刻开第二枪，等下个节点 |

节奏基准（5280 同期总结）：
> "熊市最重要就一个字：等。一个节点不管你是赚钱还是亏钱，一个节点做完就是一个节点，不管赚亏都不能留恋，然后等到下个节点。关键字就是等。"

**交易的最小单位是"节点"，不是"天"。**

## 逻辑有效性分层（关键，勿误读为矛盾）

7/29："逻辑还是要行情正常的时候才有用……因为逻辑没用，没办法成为股价的弹性。"
7/30："你们要明白现在的市场是很看重逻辑的。"

正解：**退潮期逻辑从进攻工具退化为防守工具。** 不再给弹性（赚不到钱），但仍能排除（少亏钱）。所以退潮期照样研究逻辑，只是研究结果只能用来否决，不能用来下注。

## 反弹 vs 反转

判据单一：
> "这地方如果行情是反转的话，是指数的新高，所以不用太去计较这一两天。如果只是反弹，那么就这样了。"
> "反转的话就是前菜，反弹的话就保持风控。"

**判不出来时默认按反弹处理**（不对称风险下的正确默认）。

## 概率更新机制（体系精髓）

有人问他风控体系怎么来的：
> "看自己的出手和持仓就知道了，再加上对大环境的判断就基本知道了。"

实际运行：

```
第 1 笔一成试错 → 不赚钱 → 当日停手，反转概率下调
第 2 笔一成试错 → 不赚钱 → "从这两次出手情况看，反转的概率只有 30% 了"
                          → "如果周一无法反包，只有 20%"
                          → 下一笔仓位与频率据此再降
```

**试错结果是最诚实的环境读数**，比任何指标可靠，因为它是用真钱采样的。这也是必须保留一成仓的原因：没有仓位就没有采样。

## 状态迁移触发

| 迁移 | 触发条件 |
|---|---|
| 主升 → 顶部 | 顶部信号命中 2 项以上（见 signals.md） |
| 顶部 → 退潮 | 强势股全面补跌 + 昨日强势股无溢价 |
| 退潮 → 修复节点 | 极端超跌 + 大资金现身 |
| 修复节点 → 退潮 | 该次试错不赚钱 |
| 退潮 → 主升 | **指数新高**（唯一判据，慎用） |
| 任意 → 升一档谨慎 | 连续 3 笔试错亏损 → 强制重新标定 |

## 仓位权限的来源

> "你们不是问怎么才能推仓位嘛？很简单嘛——防守的时候别人亏了你没亏，下一波的时候，你就比别人能猛。"
> "这地方少亏的就是你后面赚的。"
> "每多一天，他们就多亏五到十个点，你们就领先他们五到十个点。"

**重仓资格由前一阶段防守业绩换来，不由看好程度换来。**

> "这边天天吵着抄底的全是前面亏麻掉的，我们没这个需求。"

想抄底的冲动本身就是前期亏损的症状。

## 赔率反推仓位

不是拍脑袋，是算的：
> "预判买点抄底三次亏两次，关键亏一下就是十个点起步，所以我感觉这边套利就最多一成了。"

胜率 1/3、单次亏损 10%+ → 单笔上限一成。

净值贡献同步验算：
> "你买一成仓，今天这个票净值贡献 3%；你买两成，6%。"

**两边都算：赔率定上限，净值贡献定值不值得。**

## 连胜是危险信号

> "下降趋势里面，这种赚到钱了一定会继续出手，然后就怕不赚钱了。所以还是要极其谨慎。"

下跌趋势中的成功试错会诱发加倍下注，恰是最危险时点。

## 不出手也是操作

> "今天不出手，等于又逃顶了。"
> "这地方完全没必要和他们争那一个点。很多人上周开始非要争那个冰点，结果多亏 20 个点。"
> "这行情少努力少亏点，还能有助于身心健康。"
> "现在这边的行情，体感上来说，真不如不做。一成仓都感觉很浪费。"
