# 数据采集协议

把体系判据翻译成可查询的数据项。**没有数据不下结论**是硬规则。

## 采集顺序（有先后依赖，不要乱序）

```
第 0 步  确认交易日与时点（是否开市、盘中还是盘后、上一交易日是哪天）
第 1 步  昨日涨停股名单  ──┐
第 2 步  今日大盘与板块   ──┼→ 判据 3（溢价）、5（补跌）、6（轮动）、4（弹性）
第 3 步  昨日强势股今日表现┘
第 4 步  涨停家数/连板高度 → 判据 2（打板位置环比）
第 5 步  融资余额变化      → 杠杆状态、强平判断
第 6 步  资金面（北向/主力）→ 参与者结构
第 7 步  个股专项（仅任务 C/D 需要）
```

第 1、2、4 步可并行发起，第 3 步依赖第 1 步结果。

## 判据 → 数据项对照

| 判据 | 需要的数据 | 检索关键词 |
|---|---|---|
| 昨日强势股今日溢价 | 昨涨停股今日平均涨幅、炸板率 | `昨日涨停股今日表现 溢价 <日期>` |
| 强势股补跌完成度 | 前期主线龙头近 3 日累计跌幅 | `<主线名> 龙头 补跌 <日期>` |
| 轮动速度 | 板块涨幅榜早盘 vs 尾盘对比 | `<日期> A股 板块轮动 早盘 尾盘` |
| 逻辑票是否给弹性 | 有明确产业逻辑的票今日涨跌 | `<主线名> 今日 涨跌 逻辑` |
| 打板位置环比 | 涨停家数、最高连板数、平均涨停价位 | `<日期> 涨停家数 连板 最高板` |
| 估值标尺 | 主线板块当年 PE vs 明年 PE | `<板块> 估值 2026 PE 今年 明年` |
| 极端超跌 | 单日跌停/双跌停名单 | `<日期> 跌停 名单` |
| 杠杆状态 | 两市融资余额日变化 | `两市融资余额 <日期> 减少` |
| GJD 介入 | 沪深300ETF/中证500ETF 异常放量、红利板块强势 | `<日期> ETF 放量 国家队 红利` |
| 顶部信号1 | 大型 IPO 申报/过会/定价进度 | `<行业> 龙头 IPO 上市 进展` |
| 顶部信号2 | 主线叙事阶段（涨价/扩产/变现） | `<主线> 涨价 扩产 资本开支` |
| 顶部信号3 | 研报是否在反驳质疑 | `<个股> 研报 传言 筹码` |
| 顶部信号7 | 央行投票分歧、国债利率 | `央行 议息 投票 国债收益率 <月份>` |

## 来源优先级

| 级别 | 来源 | 用途 |
|---|---|---|
| 一级 | 交易所/上市公司公告、招股书、定期报告 | 事实基准，可直接下注 |
| 一级 | 央行/统计局/行业协会数据 | 宏观与产业事实 |
| 二级 | 财经媒体行情数据（涨停、融资余额、资金流） | 状态判据主要来源 |
| 三级 | 卖方研报 | **看用词而非结论**（见 signals.md 4.3） |
| 四级 | 论坛/自媒体/小作文 | 只作情绪样本，不进决策；但知道它对量化有效 |

> "因为现在都是量化，小作文对他们有用。"

小作文的价值在于预判量化行为，不在于内容真假。

## 反指来源（明确当反向指标）

> "外面人只想把货卖给你。"
> "A股就是熊市的时候，每个修复节点外面吹的和主升一样。"
> "他们没你们做得好，比你菜的人的呢，为什么要看。"
> "别人发我的，我也无法辨别真假。"（且推荐人自己周五就割了）

熊市修复节点的鼓吹强度与机会大小无关，这条要特别注意——它会让人误把反弹当反转。

## 缺失降级规则

| 缺失情况 | 允许输出 | 禁止输出 |
|---|---|---|
| 全部实时数据缺失 | 框架说明、待核验清单 | 任何仓位/出手建议 |
| 仅缺 1–2 项判据 | 带置信度标注的状态判定 | 满参数集操作建议 |
| 缺个股基本面 | 逻辑链结构分析 | 买入/卖出结论 |
| 数据为隔夜/非当日 | 标注"截至 X 交易日"的判定 | 当日出手建议 |
| 只有二级源、无一级源 | 倾向性判断 | 下注级结论 |

降级时必须在【数据】段明写缺哪几项、以及缺口如何影响结论。

## GJD 在场时的信号污染

> "这地方最大的干扰就是 GJD，看不清市场真实强度。"
> "GJD 这么每天买两下，只托不拉，就是为了缓解流动性。不然会快速下跌，快速杀跌容易连环爆杠杆。"

检测到 GJD 介入迹象（宽基 ETF 异常放量 + 红利板块逆势强） → **判据 3/4/6 的信息量下降，该日不据盘口强弱加仓**，并在输出中标注"强度信号受干扰"。

救市的性质：
> "人家是来赚钱的，救市的主要目的……救的是流动性。啥叫救流动性——救市不让老师们亏得太快，慢慢亏下去可以。"
> "我要是国家队，我宁可买高股息，为啥要去高位接盘科技。""科技真的太大了，救不起来，所以去了红利。"

**救市不改变方向，只改变斜率**——"这么一搞，又要拉长调整时间。"看到救市不要上调反转概率。

## 融资余额读法

> "两市融资余额较上日减少 366.59 亿元。""这波每天基本都是这样，说明之前确实太惨，这些减少的应该都是被爆的。"

- 连续大额下降 + 单日暴跌 → 被动强平，非主动降杠杆
- 强平是拉长的："他们是涨上去了，然后融资继续加。没钱补的，慢慢卖掉你持仓，不会一下子爆掉的。现在已经吸取 15 年教训了。"
- 推论：底部"黏糊"，不要指望一次出清后 V 型反转

## 龙虎榜反向读法

> "AI 硬件方向，如果你看到有那种大仓位抄底的，比如大几个亿抄底的，那他可能之前仓位更多，所以筹码都很差，加仓摊平成本。"
> "这一看就高位买了六个亿，然后高位横盘加了三四个亿，今天一把倒出来了，十个亿亏十个点左右。"
> "老师们你们看东西都那么不细致的嘛？连人家止盈止损往前面翻翻就能了解的东西。"

方法：**追踪同一席位的连续行为，不看单日金额。** 大额买入可能是自救摊平，不是看好。查到大额买入席位后，往前翻该席位历史，判断其成本与状态。

## 输出时的数据段格式

```
【数据】
✓ 交易日：2026-XX-XX（盘后/盘中 XX:XX）｜来源：X
✓ 昨涨停股今日均涨幅：X%（炸板率 X%）｜来源：X
✓ 涨停家数 X 家，最高 X 连板｜来源：X
✓ 融资余额：减少 X 亿｜来源：X
✗ 缺失：板块早盘/尾盘对比 → 判据 6（轮动速度）无法核验
✗ 缺失：主线当年 PE → 无法判断跌幅是否到位
影响：7 项判据核验 5 项，状态判定置信度中等
```
