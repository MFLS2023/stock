# 选股引擎：扩产逻辑法

**只在主升期用于下注。退潮期仅用于负筛选。**

核心不是"找热点"，是找产业链上那个"矛盾会转移到"的环节。

## 标准推理链（三孚股份模板）

```
① 观察：光纤价格涨疯了
② 验证：光纤企业中报很好
③ 推演：产业下一个关键点必然是光纤扩产
④ 二阶：光纤都在扩产 → 光纤环节没有壁垒 → 光纤自身会杀估值
        但扩产要消耗上游材料 → 上游材料反而受益
⑤ 定位：买上游材料（三孚股份）
⑥ 卡点：买在"后面有人意识到这点"之前
⑦ 兑现：三个板了，卖方开始科普 → 走
```

验证时刻：
> "今天光纤全部跌停，然后三孚股份涨停。这就是逻辑的美利。"

原文：
> "三孚股份是光纤扩产的逻辑。我之前埋伏三孚股份，因为光纤价格涨疯了，光纤的业绩中报很好，然后后续产业的关键点就在光纤的扩产，所以我当时买的三孚，就是卡后面有人意识到这点，三个板了开始科普了。"
> "所以我之前说，这行情，你不研究逻辑，你就是全市场成本最高、反应最慢的。"

## 二阶推论（最值钱的部分，可套任何产业）

> "那么光纤都在扩产，说明光纤企业没有壁垒，然后上游材料反而受益。"

**同一事实（扩产），对中游是壁垒证伪的利空，对上游是需求确认的利好。**

套用模板：
```
X 环节大规模扩产
  → 若 X 能被快速扩产 → X 无壁垒 → 做多 X 是错的
  → 扩产消耗 Y（设备/材料/耗材）→ Y 受益
  → 再问：Y 有壁垒吗？（见下节）有 → 买 Y；无 → 继续往上游推
```

## 卡点思维：买"还没被科普"的那一格

> "回头去看看每个买点，全部是在市场没发现的时候。"
> "我当时买的三孚，就是卡后面有人意识到这点。"

**逻辑成立度决定能不能拿，逻辑扩散度决定能赚多少。**

扩散度检查（三项符合两项以上才算卡点）：
```
□ 卖方研报还未覆盖
□ 群里/论坛没人在讨论
□ 龙虎榜没有明显资金进入
```

兑现信号：三个板 + 开始科普 = 扩散完成 = 走。

## 壁垒的两种合格来源

只有这两类值得下注：

**一、出口管制造成的独占**
> "最关键的还是我们出口管制，导致上游的一些只有我们能做。类似中船特气的逻辑。"

**二、双寡头 + 对手被削弱（国瓷材料案）**
> "就日本和国瓷两家公司，然后日本哪家公司还被限制重稀土了，日本那边产品越卖越少，所以国瓷产品越来越吃香。"

配套的重要例外：
> "当时我追涨的时候，'怎么这个位置还追'？你再回头看看他的逻辑。"

**结构性逻辑成立时，位置的重要性下降。** 但这条只适用于主升期 + 真壁垒——和退潮期"只买位置低的"是两套规则，严禁混用。

## 招股书反推受益顺序

长鑫科技招股书第 179 页原材料采购（实际用过的方法）：

| 品类 | 2025 采购额 | 同比 |
|---|---|---|
| 化学品 | 42.78 亿 | +23.58% |
| 光刻胶 | 13.95 亿 | +29.75% |
| 硅片 | 9.81 亿 | +15.02% |
| 气体 | 5.86 亿 | +21.44% |
| 靶材 | 2.53 亿 | +50.74% |

读法：**金额看空间，增速看弹性。** 靶材增速最高但基数最小（弹性大、容量小）；光刻胶金额与增速双优（最佳平衡）。

**招股书/年报的采购明细是找上游受益标的最硬的一手材料**，且是公开可查的——这是本体系里少数不依赖信息优势的部分，联网时优先用。

## 事件驱动的业绩粉饰窗口

> "寒王、芯原股份我之前买都是因为业绩。寒王没买，芯原股份是因为——这几个肯定要打扮漂亮点，长鑫科技上市之前，就这么简单的道理。等老板上市，长鑫科技上市了，你不可能说国产没业绩。"

推理：大型 IPO 前，同产业链公司有强烈动机把报表做漂亮（板块估值锚需要维持）→ **业绩超预期概率系统性上升**。

这条比"猜业绩"可靠，因为依赖动机而非数据。

更一般的业绩观：
> "就是公司的业绩什么时候放，机构什么时候买，完全都是自主调节的，和那些做传媒的公司没啥区别。"

业绩是博弈工具，不是事实。案例：德明利"藏业绩"；新易盛"他的业绩完全是厕所龙"。

## 负筛选清单（同等重要）

### 补涨票识别（MLCC 案）

> "MLCC 产业逻辑其实一般。MLCC 谁在买？前面的存储他们做的不习惯，所以 MLCC 他们当作是存储的补涨来做。至少两个游资和我说买 MLCC……前面踏空了，然后今天下午看到大盘稳了，补科技仓位，就买 MLCC。但实际上 MLCC 的逻辑就那样：每个季度 20-30% 的涨价，温和涨价，而且国内没有高端产能，信维通信子公司那个还在验证阶段。"

**方法：先问谁在买、为什么买，再问逻辑本身有多硬。** 补涨票的买方是踏空者，不是研究者。

### 无壁垒（光纤案）

> "光纤这种还在持股的，一看就是不看逻辑的。光纤的扩产没有任何壁垒。"
> "光纤跌多了可能会有反弹，但是逻辑不存在的东西，在我们模式里就是不买。"

**跌得多不构成买入理由。** 这是与抄底派的根本分歧。

### 伪概念（商业航天案，用产业史排除）

> "国产就是概念。""跌下来之后，大家发现全是贴牌的。"
> "海上回收，马斯克五年前就搞了，后来因为成本的原因放弃了。"
> "这些人亏在了没文化上面。"

方法：查这个技术路线在海外的历史结局。海外试过并放弃的，国产叙事基本是概念。

### 管理层行为矛盾（江波龙案）

> "江波龙赚了那么多钱，还在 all in 存储的价格上涨，而海外已经开始扩产了。"
> "赚的所有钱全部买现价的存储，然后自己减持，带着公司上杠杆梭哈。我是看不懂的，这种产业逻辑，有缘人冲吧。"

管理层行为（减持 + 上杠杆囤原料）与叙事矛盾 → 放弃。**"看不懂就不做"是硬规则，不是谦虚。**

## 做空视角的自检

A 股难做空，但框架可反用：
> "做多挑强的，做空找弱的。""最好做空最弱的，就是个股。"
> "像 Michael Burry 之前挑的就是 Palantir，他做空 NV 这些就是没什么道理。"
> "如果你做空，是不是挑光纤？光纤的扩产是最没门槛的。"

**自检问题：如果要做空这条链，我会空谁？** 答不出来 = 还没理清链内强弱结构 = 不该下注。

## 母子公司市值倒挂

> "这尼玛持股的公司已经比母公司市值还高了？""我们最早的时候做过这逻辑，但是当时大族数控还没有大族激光高。"

判断标准：
> "这要看行业。夕阳行业肯定估值高的要回归估值，朝阳行业大家相互比。"

倒挂本身不是机会，先判行业属性：夕阳行业向下收敛，朝阳行业向上看齐。

```

① 涨价环节：______（有数据/无数据）
② 中报验证：______
③ 扩产必然性：______
④ 二阶推论（对中游利空？对上游利好？）：______
⑤ 本标的在链中位置：______
⑥ 壁垒：□出口管制 □双寡头+对手削弱 □无壁垒（→否决）
⑦ 扩散度：□研报未覆盖 □无人讨论 □龙虎榜无资金（≥2 项才算卡点）

【负筛选】
□ 是补涨票吗？谁在买、为什么买：______

【结论】
逻辑成立度：强/中/弱/不成立
当前环境下能否下注：（退潮期即使逻辑强也只能用于负筛选）

若不可：明说不可，及原因
```
