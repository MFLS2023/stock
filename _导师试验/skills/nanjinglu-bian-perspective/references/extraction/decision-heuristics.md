# 南京路彼岸 - 决策启发式（Decision Heuristics）

## 定义
快速判断规则，用于在复杂市场环境中快速做出交易决策，无需完整分析全部信息。

---

## 启发式1：不追高，等回调或次日

### 规则描述
看好的票当天已经大涨，不在高位追入，等待回调或次日观察。

### 触发场景
- 龙头当天已经涨停
- 板块当天大幅拉升
- 分时图已经在高位

### 快速判断
**问**：现在买入是拿先手还是接后手？
- 如果是接后手 → 不买
- 等明天看龙头是否强势 → 再决定

### 底层逻辑
> "后手提前兑现先手"

追高买入 = 给先手资金提供流动性 = 被收割

### 典型案例
**错误示范**（散户行为）：
> "散户来回追涨杀跌也提供了量化的波动差价收益"

**正确做法**：
- 龙头今天涨停 → 观望
- 明天看分时图是否强势 → 如果强势再考虑介入
- 或等板块回调到情绪低点 → 拿先手

### 例外情况
**破局期的龙头确认**：
如果是破局龙首次定龙，且判断进入主升段，即使当天已涨停也可以追，因为这是"最后的有性价比上车阶段"

## 启发式2：封板率<60% + 高度压制，不做接力

### 规则描述
当日封板率低于60%，且市场高度被压制在5板以下，不参与任何接力操作。

### 触发场景
每日收盘后统计数据时

### 快速判断
```
IF 封板率 < 60% AND 市场高度 ≤ 5板
THEN 明天不做接力
ELSE IF 封板率 > 80% AND 连板数高
THEN 可做接力
```

### 底层逻辑
> "封板率是一个最重要的数据...如果封板率低（小于60%）、连板高度压制5板以下，你还怎么做接力呢？"

封板率低 = 市场情绪弱 = 接力胜率低 = 容易被埋

### 典型案例
**数据判断**：
> "比如说周五封板率79.01%...封板率大于80%就表明市场短线情绪还可以，结合连板数...做多2进3 3进4 4进5是不是都有比较高的胜率"

**反面案例**：
混沌期封板率持续低迷 → 观望为主，不做接力

## 启发式3：跌停数≥7-10，管住手看戏

### 规则描述
当日跌停数量达到7-10只或以上，当天和次日不参与任何操作。

### 触发场景
盘中或收盘后观察跌停数

### 快速判断
```
IF 跌停数 >= 7
THEN 管住手，今天和明天都观望
```

### 底层逻辑
> "跌停数为0认为市场并无风险，如跌停数众多，达到7-10或以上，那就要管住手看戏"

跌停数多 = 市场风险大 = 恐慌情绪蔓延 = 不是出手时机

### 典型案例
**历史案例**：
> "涨跌数：849:4477，这个数据的当天是由于外围战争的避险情绪影响"（极端恐慌日，应该观望）

## 启发式4：涨停数达极值，防范情绪高点

### 规则描述
涨停数达到近期极值高位时，警惕情绪见顶，准备减仓或撤退。

### 触发场景
每日统计涨停数，与近5-10日对比

### 快速判断
```
IF 今日涨停数 = 近10日最高值
AND 补涨票疯狂
THEN 准备撤退
```

### 底层逻辑
> "涨停数处于极值高位，那要防范情绪高点，盛极必衰，买盘枯竭"

涨停数极值 = 市场情绪亢奋 = 接近周期顶部 = 后手已经全部进场 = 无新增买盘

### 典型案例
**情绪高点特征**：
> "此时散户的特征是'XX已经涨很多了，我的不可能不会涨'"

当所有人都乐观时 → 就是撤退时

## 启发式5：混沌期只看不做，或小仓试错

### 规则描述
判断当前处于混沌期时，主要观望，或用小仓位跟随低位试错。

### 触发场景
- 上一轮周期刚退潮
- 市场无赚钱效应
- 板块无持续性
- 散户套牢怨气大

### 快速判断
```
IF 当前 = 混沌期
THEN 大资金观望 OR 小仓试错
```

### 底层逻辑
> "混沌期是彼岸避之大吉的阶段，原因系上一轮情绪周期的资金未出清，盘面无赚钱效应，导致市场对高度没有共识"

混沌期 = 无规律 = 胜率低 = 不是主战场

### 典型案例
**实战决策**（2026年7月中旬）：
> "目前看，只有观察，没有买入时机...我这边暂时观望，等待新主线的诞生，或者干脆放假"

## 启发式6：破局龙10天100%异动后无负反馈，重点关注

### 规则描述
某票连续超预期，突破10天100%异动线后未产生负反馈（未被砸盘），重点跟踪，可能是新周期的破局龙。

### 触发场景
混沌期末尾，观察个股表现

### 快速判断
```
IF 某票10天涨幅 > 100%
AND 未被监管问询
AND 连续多日顶住兑现压力
THEN 重点跟踪，可能是破局龙
```

### 底层逻辑
> "破局龙抵抗负反馈顶出星星之火...破10天100%异动后未产生负反馈...一旦确认破局龙出现，就意味着行情可能进入了新周期"

异动不产生负反馈 = 有大资金护盘 = 可能是新周期起点

### 典型案例
历史上的破局龙：成飞长城、中毅达等（文中多次提及但未详细描述）

## 启发式7：龙头分歧日强势封板，定龙时刻

### 规则描述
龙头在市场分歧日（兑现压力大）依然强势拉升封板，确认龙头地位，是最后的性价比上车机会。

### 触发场景
中位个股面临兑现压力的关键节点

### 快速判断
```
IF 潜在龙头前一天爆量（分歧）
AND 今天低开后迅速拉板（弱转强）
AND 板块开始助攻
THEN 龙头确认，大胆上车
```

### 底层逻辑
> "龙头的一大特征就是强势性，面对兑现，分时强势拉升封板...又或者市场兴趣不好时，前一天爆量，今天小低开后迅速拉板大长腿完成弱转强，同时板块开始出现助攻"

强势穿越分歧 = 龙头特质 = 资金认可度高

### 典型案例
**实战描述**：
> "一旦确认主线龙头主升，即使后知后觉也能跟随行情了...做起来容错率是很高的...是要大胆大仓位上车的，不能犹豫"

## 启发式8：看A做B（量化时代）

### 规则描述
看强势板块（A），但实际买入低吸标的（B），避免被量化日内收割。

### 触发场景
量化资金主导的市场环境（2026年）

### 快速判断
```
IF 市场被量化主导
AND 日内波动剧烈
THEN 看强势板块（研究方向）
     买低吸标的（实际操作）
```

### 底层逻辑
> "散户来回追涨杀跌也提供了量化的波动差价收益...很多不适应的短线资金已然被趋势资金当日本人耍"

量化收割日内波动 → 不追高 → 改为低吸 + 拉长周期

### 典型案例
**策略调整**（2026年）：
从日内追涨杀跌 → 看A做B + 中周期持有

首开、豪恩的成功：拉长持有周期，避免日内被收割

---

## 启发式9：龙头失去中周期龙护航，准备撤退

### 规则描述
总龙头涨速减缓，且无新的中周期龙接力，判断周期进入尾声，准备撤退。

### 触发场景
主升段后期，每日观察中周期龙接力情况

### 快速判断
```
IF 总龙头涨速减缓
AND 最近几个中周期龙都已涨完主升
AND 无新的中周期龙出现
THEN 准备撤退（进入补涨期或退潮期）
```

### 底层逻辑
> "如再无形成新的中周期龙头，市场维护高度的资金逐渐褪去，再参与则容易如散户一般挂在山上"

中周期龙不接力 = 板块热度衰退 = 周期接近尾声

### 典型案例
**实战判断**（2026年科技）：
科技板块多个中周期龙涨完 → 无新接力 → 提前撤场

## 启发式10：101只指标冰点 + 无破局，观望或放假

### 规则描述
101只指标（市场热度）处于极低位，且无明确破局信号，选择观望或休息。

### 触发场景
情绪冰点期

### 快速判断
```
IF 101只 = 冰点水平
AND 无破局龙出现
THEN 观望或放假
```

### 底层逻辑
> "龙虾挺有意思的，他说现在101只几乎是4月份的水平，如果市场企稳，这个位置反而是观察新主线诞生的窗口"

101只冰点 = 情绪极度低迷 = 可能酝酿新周期 = 观察窗口（但还不是买入时机）

### 典型案例
**实战决策**（2026年7月中旬）：
> "目前看，只有观察，没有买入时机"（101只冰点，但破局未确认）

## 启发式11：补涨票疯狂 + 边缘标的连续加速，撤退信号

### 规则描述
边缘补涨票开始疯狂上涨，以连续加速形式完成，且讨论主线的人非常多，这是周期尾声的开始。

### 触发场景
主升段后期观察补涨情况

### 快速判断
```
IF 边缘补涨票连续加速上涨
AND 市场讨论热度极高
AND 散户说"XX已经涨很多了，我的不可能不会涨"
THEN 立即撤退
```

### 底层逻辑
> "补涨已经是行情尾声的开始...主线明确时，补涨票上涨会非常迅速，多数是以连续加速的形式完成...如果在这个时候很多散户固守的所谓基本面票到此时都未能有一波明显的行情的话，多半最后也是不可能再大涨了"

补涨疯狂 = 后手全部入场 = 买盘枯竭在即 = 主力借机出货

### 典型案例
**历史规律**：
> "大家可以复盘，主线明确时，补涨票上涨会非常迅速"

## 启发式12：天道压制一出现，立即无条件退出

### 规则描述
任何天道压制信号（政策/监管/媒体定调），立即退出相关板块，不问盈亏。

### 触发场景
- 新闻联播点名批评
- 监管层表态
- 交易所问询函
- 政策导向转变

### 快速判断
```
IF 出现任何天道压制信号
THEN 立即退出
     不存在博弈空间
     不问当前盈亏
```

### 底层逻辑
> "从那之后我发誓绝对不头铁...多点从大局出发理解天道，对我们长期活在市场里，是有好处的"

对抗天道 = 账户归零风险 > 错过机会成本

### 典型案例
**关键教训**：
航天周期"头铁" → 重大损失 → 形成铁律

**实战应用**（2026年7月）：
"天道压制科技" → 立即撤场 → 不管技术面多强

|------|-----------|---------|---------|----------|
| 1 | 不追高 | 标的当天已大涨 | 是接后手吗？→是→不买 | 任何时候 |
| 2 | 封板率<60%不接力 | 收盘数据统计 | 封板率<60% + 高度≤5板 → 不接力 | 每日复盘 |

| 6 | 破局龙10天100% | 混沌期末尾 | 10天>100% + 无负反馈 → 跟踪 | 周期起点 |

| 8 | 看A做B | 量化主导市场 | 看强势 + 买低吸 | 2026年后 |

## 启发式的使用优先级

### 第一优先级（硬约束）
- **启发式12**：天道压制 → 立即退出
- **启发式3**：跌停≥7 → 管住手

### 第二优先级（周期定位）
- **启发式5**：混沌期 → 观望
- **启发式6**：破局龙信号 → 重点跟踪
- **启发式7**：定龙时刻 → 大胆上车

### 第三优先级（日常操作）
- **启发式1**：不追高
- **启发式2**：封板率判断
- **启发式8**：看A做B

### 第四优先级（退出信号）
- **启发式4**：涨停数极值
- **启发式9**：无中周期龙接力
- **启发式11**：补涨疯狂

---

## 启发式的演进性

### 稳定核心（长期不变）
- 不追高
- 封板率判断
- 跌停数管住手
- 天道压制退出

### 动态调整（应对市场变化）
- **2024年前**：无"天道压制"启发式
- **航天教训后**：增加"天道压制优先"
- **2026年量化时代**：增加"看A做B"
- **未来**：可能继续增加新规则
