## 测试题组1：周期识别的边界情况

### T1.1 混沌期边界模糊问题（改编自Q1）

**诱导性问题**：
"现在涨停数30个（刚好临界值），跌停数6个（差一点到7），101只指标18（略高于冰点），有一个板块有点起色但不明显。算混沌期吗？如果算，为什么跌停数不到7？如果不算，那是什么阶段？"

**标准答案预期**：
- 应该识别为混沌期边界状态
- 承认数据在临界值，判断有模糊性
- 强调"看不懂就不做"原则更重要
- 不应该强行分类或给出确定性操作建议

**发现的问题**：
🔴 **致命问题1：阈值过于僵化**
- SKILL.md中的阈值（涨停<30，跌停≥7）是硬性指标
- 实际市场中，29个涨停和31个涨停可能本质一样
- 缺少"临界状态处理"的指导
- 可能导致用户机械套用数据

**修复建议**：
在"模型1: 情绪周期四阶段循环"的"边界条件"部分添加：
```markdown
**阈值使用说明**：
- 数据阈值是参考值，非绝对临界点
- 临界状态（如涨停数28-32）应结合多个指标综合判断
- 核心原则："看不懂就不做" > 硬性套用阈值
```

### T1.2 破局龙的诱导性测试（改编自Q2）

**刁钻问题**：
"某只票'智能机械'10天涨了120%（超过100%），封板很强，但是它从2元涨到4.4元，绝对价格很低，而且它的板块概念是'智能+机械+新能源+军工'（概念很杂）。这算破局龙吗？"

**标准答案预期**：
- 符合10天100%的硬指标
- 但需要结合板块画像三维度判断（辨识度问题）
- 概念太杂=辨识度低，可能不是真正的破局龙
- 低价股可能有炒作嫌疑，需警惕

**发现的问题**：
🟡 **重要问题1：破局龙识别维度不全**
- SKILL只强调"10天100% + 无负反馈"
- 缺少板块画像和破局龙识别的关联
- 没有提到低价股陷阱或概念混杂的风险

**修复建议**：
在"模型1: 情绪周期四阶段循环"的"破局期"部分添加：
```markdown
**破局龙识别补充**：
- 不仅看涨幅，还要看板块画像（辨识度、持续性）
- 警惕低价股炒作（绝对价格过低可能是游资题材炒作）
- 概念太杂的标的辨识度差，难成大周期龙
```

### T1.3 情绪高点的矛盾测试（改编自Q3）

**矛盾问题**：
"今天涨停数120个（极值），边缘票疯狂，但龙头封板率85%，而且刚出现一个新的中周期龙接力。你说应该撤，但'价格未破坏持有不动'原则呢？这两个原则冲突了怎么办？"

**标准答案预期**：
- 识别出原则冲突（情绪高点提前撤 vs 价格领先原则）
- 明确优先级：情绪周期判断 > 价格形态（在极端情况下）
- 解释：情绪高点的"提前撤"是主动止盈，价格破坏是被动止损
- 补充：新中周期龙可能是"虚假接力"（补涨期特征）

**发现的问题**：
🔴 **致命问题2：原则冲突没有明确优先级**
- "模型3: 价格领先于情绪原则"和"模型6: 情绪高点提前撤"可能冲突
- SKILL.md中没有明确哪个优先
- 用户在实战中会困惑

**修复建议**：
在"模型3: 价格领先于情绪原则"的"边界条件"部分添加：
```markdown
**与情绪周期冲突时的优先级**：
- 补涨疯狂期 → 情绪判断优先，提前止盈（主动撤退）
- 主升段 → 价格形态优先，持有不动（被动止损）
- 判断依据：看周期位置，补涨期是主动减仓期
```

## 测试题组2：决策启发式的诱导性测试

### T2.1 天道压制的边界测试（改编自Q5）

**边界问题**：
"我的票收到问询函，但问询的是财务问题（业绩预告），不是炒作问题。监管只是例行核查，不是打压。这也算天道压制吗？也要无条件退出？"

**标准答案预期**：
- 问询函确实是天道信号
- 但应该区分问询性质：炒作问询（高危） vs 常规财务问询（相对低危）
- 即使如此，谨慎起见建议减仓观望
- 承认"天道判断"本身也有灰度

**发现的问题**：
🟡 **重要问题2：天道压制分类不够细**
- SKILL只说"问询函、约谈、政策打压"
- 没有区分问询函的性质（炒作 vs 财务 vs 信披）
- 可能导致过度反应或误判

**修复建议**：
在"模型7: 天道压制优先原则"的"触发条件"部分细化：
```markdown
**天道压制信号分级**：
- **高危（立即无条件退出）**：炒作问询、交易异常问询、约谈、官媒点名
- **中危（减仓观望）**：常规财务问询、信披核查
- **低危（关注但不一定退出）**：一般性提示函

不确定性质时，按高危处理。
```

### T2.2 混沌期重仓的反向诱导（改编自Q6）

**诱导问题**：
"你说混沌期不要重仓，但巴菲特说'别人恐惧我贪婪'，混沌期不正是别人恐惧的时候吗？你的'情绪低点拿先手'和'混沌期不重仓'矛盾了吧？"

**标准答案预期**：
- 识别出概念混淆："情绪低点"≠"混沌期任何时刻"
- 澄清：情绪低点拿先手是指"混沌期末期+破局龙出现前夕"
- 混沌期大部分时间是观望期，不是布局期
- 巴菲特是价值投资，场景不同（方法论边界）

**发现的问题**：
🟡 **重要问题3："情绪低点拿先手"时机不明确**
- "模型6"中说"情绪低点拿先手"
- 但没有明确"什么时候算低点"
- 混沌期全程都是低点吗？还是只有末期？
- 与"混沌期观望"有时机区分不清的问题

**修复建议**：
在"模型6: 情绪低点拿先手/高点提前撤"中细化"运作机制"：
```markdown
**低点拿先手的具体时机**：
- 不是混沌期全程，而是"混沌期末期+出现破局迹象"时
- 具体信号：101只指标见底反弹、跌停数连续<5、出现异动标的
- 操作：小仓试错（1-2成），不是重仓
- 与"混沌期观望"不矛盾：观望是主策略，试错是辅策略
```

### T2.3 追高场景的灰度测试（改编自Q4）

**灰度问题**：
"龙头票上午涨了8个点，但它是从跌5个点反弹上来的（分时图V型），现在还是比昨天收盘价低。这算追高吗？"

**标准答案预期**：
- 识别出这是"回调后的追赶"，不是典型追高
- 如果是龙头分歧日反包，这可能是"定龙时刻"（启发式7）
- 需要结合具体场景：是不是龙头、是不是分歧日
- 启发式1"不追高"主要指跟风和情绪化追涨

**发现的问题**：
⚪ **次要问题1："追高"定义不够明确**
- 启发式1只说"不追高，等回调或次日"
- 但没有定义什么算"追高"（绝对涨幅？相对位置？情绪状态？）
- 分歧日反包是例外情况，但SKILL中没有明确关联

**修复建议**：
在"启发式1: 不追高，等回调或次日"后补充：
```markdown
**例外情况**：
- 龙头分歧日反包（启发式7"定龙时刻"）可以参与，不算追高
- 判断关键：是不是龙头、是不是分歧后封板、有无回调空间
```

## 测试题组3：数据解读的陷阱测试

### T3.1 封板率的复合条件陷阱（改编自Q7）

**陷阱问题**：
"龙头封板率55%（<60%），市场高度5板，但今天涨停数有80个（很高），而且有两个新的中周期龙出现。你说不接力，但这么多信号都很强，真的不能做吗？"

**标准答案预期**：
- 启发式2明确：封板率<60% + 高度压制 = 不接力（不管其他信号）
- 涨停数多可能是补涨或跟风票，不代表龙头环境好
- 接力看的是龙头强度，不是市场广度
- 这是"快判"启发式，优先保命

**发现的问题**：
⚪ **次要问题2：启发式的刚性 vs 灵活性没有说明**
- 启发式是"快判"规则，但没有说明能否被推翻
- 用户可能疑惑："如果其他信号都很强，这个启发式还适用吗？"
- 需要明确启发式的"优先级"或"刚性程度"

**修复建议**：
在"决策启发式"章节开头添加：
```markdown
**启发式使用原则**：
- 启发式是"快判"规则，优先级高于复杂分析
- 多个信号冲突时，遵守更保守的那个（保命第一）
- 不要因为"还有其他好信号"而忽略风险启发式
```

### T3.2 跌停数的反向测试（改编自Q8）

**反向问题**：
"今天跌停数12个，但都是前期的妖股和垃圾票在跌停，龙头板块一点事没有，甚至龙头还在涨。你说'管住手'，但我的票好好的，为什么不能加仓？"

**标准答案预期**：
- 跌停数≥7是市场恐慌信号，不管是哪些票跌停
- 恐慌情绪会传染，今天安全不代表明天安全
- 启发式目标是降低胜率风险，不是100%准确
- "看戏"比"抓机会"更重要

**发现的问题**：
⚪ **次要问题3：启发式背后的"为什么"不够充分**
- 启发式给了"快判"，但"底层逻辑"比较简略
- 用户可能挑战："我的情况是例外"
- 需要补充"为什么不能看运气抓例外"

**修复建议**：
在各启发式的"底层逻辑"部分，统一补充：
```markdown
**为什么不能看例外**：
- 启发式是为了"降低失误率"，不是"抓住所有机会"
- 市场中总有例外，但追求例外会导致整体亏损
- 宁可错过机会，不可犯致命错误
```

### T3.3 101只指标的持续性测试（改编自Q9）

**持续性问题**：
"101只指标冰点一个月了，我一直等，结果错过了外面其他板块的行情。这个指标是不是失效了？"

**标准答案预期**：
- 101只指标是情绪指标，不是全市场指标
- 它主要适用于"低价股情绪驱动"的周期
- 如果市场主线不在低价股（如大盘蓝筹行情），101只指标不适用
- 方法论有边界：只适用A股短线情绪板块

**发现的问题**：
🟡 **重要问题4：指标适用场景没有明确**
- 7指标系统没有说明"适用于什么行情"
- 101只指标是针对低价股情绪的，但SKILL没有强调
- 用户可能误以为7指标是全市场通用的

**修复建议**：
在"模型2: 数据量化情绪系统"的"边界条件"部分添加：
```markdown
**指标适用场景**：
- 7指标主要适用于"短线情绪驱动+低价股活跃"的市场环境
- 如果市场主线是大盘蓝筹、价值股，情绪指标可能失效
- 101只指标特别依赖低价股活跃度
- 判断指标是否失效：看市场主线在哪里
```

## 测试题组4：板块分析的逻辑漏洞

### T4.1 板块画像的权重问题（改编自Q10）

**权重问题**：
"A板块：辨识度高（AI机器人），持续性中（政策支持但不明朗），空间大  
B板块：辨识度中（新能源车），持续性高（产业确定），空间中  
哪个更好？三个维度怎么权衡？"

**标准答案预期**：
- 板块画像三维度没有固定权重
- 短线情绪周期更看重"辨识度"和"空间"（爆发力）
- 长线价值投资更看重"持续性"（稳定性）
- 结合方法论边界：短线打法优先A板块

**发现的问题**：
🟡 **重要问题5：板块画像三维度没有权重指引**
- "模型4"只列出三维度，没有说明如何权衡
- 不同维度冲突时，用户无法决策
- 短线 vs 长线的维度侧重不同，但没有说明

**修复建议**：
在"模型4: 板块画像方法"的"运作机制"部分添加：
```markdown
**三维度权重指引（短线情绪周期）**：
1. 辨识度 > 空间想象力 > 持续性
2. 短线看爆发力，辨识度是基础（否则资金无法快速聚集）
3. 持续性在短线中不是首要因素（但太差会导致一日游）
4. 长线价值投资的权重相反（持续性第一）
```

### T4.2 中周期龙护航的量化判断（改编自Q11）

**量化问题**：
"大周期龙走到8板，最近出现了一个3板的票，涨幅也不错。这算中周期龙接力吗？怎么判断是不是'护航'？"

**标准答案预期**：
- 中周期龙判断标准：10天100%、封板强度、所属同一板块
- 3板不一定算中周期龙（可能只是跟风票）
- 护航的本质：维持板块热度、吸引增量资金
- 需要观察：新龙是否被市场认可、是否持续

**发现的问题**：
🔴 **致命问题3：中周期龙的识别标准不明确**
- "模型5"只说"中周期龙接力护航"，但没有定义如何识别中周期龙
- 跟模型1的"破局龙"标准一样吗（10天100%）？
- 中周期龙和跟风票的区别是什么？

**修复建议**：
在"模型5: 中周期层层递进护航总龙"中添加：
```markdown
**中周期龙识别标准**：
- 符合破局龙特征：10天接近或超过100%、封板强度高
- 属于同一板块或相关联板块
- 市场认可度高（成交量、换手率、封板率）
- 与跟风票区别：中周期龙有独立爆发力，跟风票只是跟涨
```

## 测试题组5：表达DNA的模仿测试

### T5.1 核心短语的过度使用陷阱

**陷阱问题**：
"我问你任何问题，你都说'看不懂就不做'，这是不是在逃避？你能不能给点具体建议？"

**标准答案预期**：
- 解释"看不懂就不做"是核心原则，不是逃避
- 承认：如果用户提供了完整数据，应该给出具体分析
- 但"具体分析"是基于框架，不是推荐股票
- 边界：教方法论，不教买什么票

**发现的问题**：
⚪ **次要问题4：表达DNA可能导致过度使用固定短语**
- 核心短语"看不懂就不做"唯一性高，但不能滥用
- 需要平衡：保持语言特色 vs 避免机械重复
- SKILL中没有"过度使用"的提醒

**修复建议**：
在"表达DNA"章节末尾添加：
```markdown
**使用原则**：
- 核心短语是标志性表达，但不要滥用
- 同一对话中避免重复超过2次
- 核心短语应该在关键决策点使用，不是每句话都带
```
