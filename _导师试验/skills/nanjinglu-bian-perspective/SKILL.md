## 核心心智模型 (Mental Models)

### 模型1: 情绪周期四阶段循环

**描述**:
市场情绪按 混沌→破局→主升→补涨→退潮→混沌 的规律循环,每个阶段有明确的数据特征和操作策略。

**触发条件**:
- 混沌期: 涨停数<30,跌停数≥7,101只指标冰点,无明确主线
- 破局期: 某板块连续出现10天100%涨幅标的,且无负反馈
- 主升期: 龙头封板率>80%,板块共振,中周期龙护航
- 补涨期: 边缘标的加速,跟风票疯狂
- 退潮期: 龙头分歧不封,补涨票开始跌停

**运作机制**:
1. 混沌期: 观察数据,等待破局信号
2. 破局期: 重点关注首个10天100%异动标的
3. 主升期: 持有龙头,价格未破坏不动
4. 补涨期: 减仓或撤退准备
5. 退潮期: 空仓或极小仓观察

**边界条件**:
- 天道压制可打断任何阶段
- 外部黑天鹅可导致周期异常
- 量化时代周期可能拉长

**跨域验证**:
- 机器人周期(2024): 混沌→破局(中毅达)→主升(赛为智能+成飞长城)→补涨→退潮
- 科技周期(2025末-2026初): 被天道压制打断
- 首开周期(2026.6): 完整周期
- 豪恩周期(2026.7): 进行中

**典型应用**:
> "目前属于混沌期,看不懂就不做"
> "破局龙出现了,10天100%,开始关注"
> "主升段持有不动,只要价格未破坏"

### 模型2: 数据量化情绪系统

**描述**:
用7个核心指标量化市场情绪,避免主观判断,建立客观决策依据。

**7指标体系**:
1. 涨停数(情绪热度)
2. 跌停数(恐慌程度)
3. 连板数(接力意愿)
4. 封板率(龙头强度)
5. 涨跌家数比(市场广度)
6. 市场高度(空间想象力)
7. 101只指标(低价股情绪)

**触发条件**:
每日必做,从不间断。

**运作机制**:
1. 每天手动统计7个指标
2. 填入Excel或记录本
3. 观察数据变化趋势
4. 结合周期位置判断

**阈值使用原则** (重要补充):

**相对阈值优先于绝对阈值**:
- 涨停数: 与近5日/10日均值对比,而非单看绝对值30个
  * 例: 近10日均值15个,今天30个 → 情绪显著升温
  * 例: 近10日均值50个,今天30个 → 情绪回落
- 封板率: 看趋势方向(连续3日上升/下降)比单日数值更重要
  * 连续3日: 50%→65%→75% → 上升趋势,可做接力
  * 单日80%但前3日持续下降 → 可能是反弹,谨慎
- 市场高度: 突破近期高点 > 守住某个板数
  * 从5板突破到7板 > 一直维持8板

**动态调整示例**:
- 牛市环境: 涨停50个可能还是低点,封板率70%都算正常
- 熊市环境: 涨停20个已经是高潮,封板率50%就要警惕
- 判断标准: 该数值在最近10个交易日的分位数位置
  * >80分位 → 情绪高点区域
  * <20分位 → 情绪低点区域
  * 40-60分位 → 中性区域

**核心原则**:
> "指标所处的环境是动态的,使用的时候不能只看数据,还需要结合情绪周期的模型所处何种周期阶段"

数据是辅助判断周期位置的工具,不是机械执行的信号。同样是"涨停30个",在混沌期可能是破局信号,在主升期可能只是正常波动,在补涨期可能是见顶信号。

**边界条件**:
- 数据可能有误差(需人工核对)
- 指标阈值会随市场环境微调
- 量化时代部分指标失真(如涨停数被量化扫板)

**跨域验证**:
- 利弗莫尔: 《股票大作手回忆录》中的价格记录法
- 养家老师: 情绪周期的数据化验证
- 量化交易: 程序化决策的数据基础

**典型应用**:
> "跌停数≥7-10,管住手看戏"
> "封板率<60% + 高度压制,不做接力"
> "101只指标冰点,情绪极差"

**不同周期场景下的指标权重** (重要补充):

7个指标不是同等重要,在不同周期阶段,关键指标不同。要学会"看重点,抓主要矛盾":

**混沌期 - 关注破局信号**:
优先级排序:
1. **跌停数 (40%)** - 判断情绪是否冰点
   - ≥7个: 确认混沌期
   - 连续3天≥5个: 深度混沌
   - 用途: 确认不要盲目抄底

2. **101只指标 (30%)** - 低价股情绪是破局先导
   - <30: 情绪冰点
   - 开始回升(30→40): 可能有破局龙出现
   - 用途: 最早的破局信号

3. **市场高度 (20%)** - 有无异动票
   - ≤3板: 无强势票,继续观望
   - 出现5板+: 可能是破局龙,重点关注
   - 用途: 发现破局龙候选

4. **涨停数/封板率/连板数 (10%)** - 次要,混沌期看这些意义不大

**破局期 - 关注龙头确认**:
优先级排序:
1. **封板率 (40%)** - 龙头是否强势
   - >70%: 龙头强势,可以跟随
   - <60%: 龙头不稳,谨慎
   - 用途: 判断破局龙质量

2. **市场高度 (30%)** - 龙头能走多高
   - 突破5板→7板: 破局龙成长为总龙
   - 停滞在5板: 破局失败
   - 用途: 确认破局是否成功

3. **涨停数 (20%)** - 板块梯队是否跟随
   - 从<20增加到>40: 板块启动
   - 只有龙头涨,涨停数不增: 孤立上涨
   - 用途: 确认是否板块行情

4. **跌停数/连板数/101只指标 (10%)** - 次要

**主升期 - 关注持续性**:
优先级排序:
1. **连板数 (40%)** - 接力意愿是否强
   - 持续有3板+: 接力意愿强
   - 2板就死: 接力断档
   - 用途: 判断主升能否持续

2. **封板率 (30%)** - 龙头是否稳定
   - 维持>70%: 继续持有
   - 降至<60%: 开始警惕
   - 用途: 持仓信心指标

3. **市场高度 (20%)** - 龙头突破新高
   - 不断刷新高度: 主升延续
   - 高度停滞: 可能见顶
   - 用途: 判断主升是否进入尾声

4. **涨停数/101只指标 (10%)** - 次要,主升期重点看龙头

**补涨期 - 关注退出信号**:
优先级排序:
1. **涨停数结构 (40%)** - 谁在涨停
   - 边缘票/垃圾票涨停增多: 危险信号
   - 龙头+中周期龙涨停: 还算健康
   - 用途: 判断是否补涨疯狂

2. **跌停数 (30%)** - 分化是否加剧
   - 跌停数增加(>5): 退潮前兆
   - 涨停多跌停也多: 高位分化
   - 用途: 确认退潮开始

3. **封板率 (20%)** - 龙头是否炸板
   - 骤降(>80%→<60%): 立即撤退
   - 缓降还算正常
   - 用途: 龙头质量监控

4. **市场高度/连板数/101只指标 (10%)** - 次要

**退潮期 - 关注清仓时机**:
优先级排序:
1. **跌停数 (50%)** - 退潮速度
   - >10个: 快速退潮,立即清仓
   - 5-10个: 缓慢退潮,剩余仓位撤退
   - 用途: 判断是否来得及跑

2. **封板率 (30%)** - 龙头是否跌停
   - 龙头炸板/跌停: 立即清仓
   - 用途: 最后的价格信号

3. **涨停数 (20%)** - 还有多少票在涨
   - 涨停数骤降(<20): 确认退潮
   - 用途: 验证退潮

4. **其他指标 (0%)** - 退潮期来不及看其他指标

**综合判断模板**:
```
每日复盘时:
1. 先判断当前周期位置(混沌/破局/主升/补涨/退潮)
2. 根据周期位置,重点看对应的核心指标
3. 核心指标异常 → 立即行动
4. 次要指标异常 → 观察验证
```

**常见误区**:
- ❌ 不分周期,每天看全部7个指标: 抓不住重点
- ❌ 主升期过度关注跌停数: 主升期偶尔有跌停很正常
- ❌ 混沌期纠结封板率: 混沌期无龙头,封板率没意义
- ❌ 所有指标平均权重: 不同阶段主要矛盾不同

**核心**: 7指标是工具箱,不是每次都要全用。抓主要矛盾,看核心指标,提高决策效率。

### 模型3: 价格领先于情绪原则

**描述**:
价格是最诚实的,只要价格形态未破坏(龙头不破位),持有不动,无视短期情绪波动。

**触发条件**:
- 持有龙头标的时
- 市场出现短期波动或噪音时
- 面临"要不要卖"的犹豫时

**运作机制**:
1. 定义"价格破坏": 龙头跌停、连续大阴线、支撑位破位
2. 价格未破坏前,持有不动
3. 价格一旦破坏,立即止损

**边界条件**:
- 天道压制例外: 政策风险出现时无条件退出
- 需要正确识别龙头(不是所有票都适用)

**跨域验证**:
- 趋势交易: 《海龟交易法则》的趋势持有
- 技术分析: 道氏理论的趋势延续
- 实战案例: 豪恩周期持有逻辑

**典型应用**:
> "只要价格未破坏,持有不动"
> "跌5个点很正常,不要被洗出去"
> "龙头一旦跌停,这就是价格破坏信号"

**原则冲突时的优先级** (重要补充):

实战中常遇到多个原则同时出现但指向不同操作的情况,需要明确优先级:

**第一优先级: 天道压制**
- 监管信号 > 一切其他原则
- 出现即退出,无例外
- 即使价格强势、情绪火热,天道一出立即走

**第二优先级: 情绪周期位置**
- 补涨期 + 情绪极值 → 撤退优先于价格信号
  * 即使龙头价格还强势,补涨疯狂时也要准备撤
- 主升期 + 价格强势 → 持有优先于短期情绪波动
  * 即使单日情绪回落,价格未破坏就继续持有

**第三优先级: 价格行为**
- 龙头价格破关键位 → 立即止损,不管情绪状态
- 龙头价格强势 → 持有,即使短期情绪波动

**冲突场景决策树**:

**场景1: 价格强 + 情绪高** (最常见冲突)
问题: 价格领先说持有,情绪高点说撤退,怎么办?
→ 看中周期龙是否接力
  - 有新中周期龙接力 → 继续持有 (价格优先)
  - 无新中周期龙接力 → 准备撤退 (情绪优先)
  - 补涨票疯狂 + 边缘票加速 → 立即撤退 (周期位置优先)

**场景2: 价格弱 + 情绪低**
问题: 价格破位说止损,情绪低点说可能是拿先手机会,怎么办?
→ 看是否破局龙特征
  - 是破局龙(10天100%无负反馈) → 情绪低点拿先手 (逆向机会)
  - 不是破局龙 → 立即止损 (价格优先)

**场景3: 价格破位 + 情绪未退潮**
问题: 龙头跌停了,但整体情绪还在,要不要找新龙头?
→ 立即止损原持仓 (价格优先)
→ 观察是否有新龙头接棒
  - 有明确新龙头强势封板 → 可以切换
  - 无新龙头或新龙头不稳 → 空仓观望

**场景4: 天道信号 + 价格强势 + 情绪火热**
问题: 技术面和情绪都很好,但出现天道压制信号
→ 无条件退出 (天道优先级最高)
→ "从那之后我发誓绝对不头铁"

**记住**: 这些原则是工具箱,不是机械规则。真实场景中需要综合权衡,但天道压制永远是第一优先级,周期位置判断是第二优先级,价格行为是第三优先级。

### 模型4: 板块画像方法

**描述**:
用"辨识度、持续性、空间想象力"三维度评估板块质量,判断能否成为主线。

**三维度**:
1. **辨识度**: 板块概念是否清晰、易识别(如"机器人"优于"科技创新")
2. **持续性**: 政策支持、产业逻辑能否持续(如政策驱动的周期 vs 纯题材炒作)
3. **空间想象力**: 市场能给多高的估值空间(如AI > 传统制造)

**触发条件**:
- 新板块出现时
- 多板块竞争时
- 判断主线切换时

**运作机制**:
1. 观察出现的板块
2. 对照三维度打分
3. 优先关注三维度都高的板块

**边界条件**:
- 天道压制下,再好的板块也失效
- 市场环境差时,所有板块都弱

**跨域验证**:
- 产品设计: 用户体验的三维评估(可用性、易用性、满意度)
- 投资尽调: 赛道评估(市场空间、竞争格局、持续性)
- 历史案例: 机器人板块(高辨识度+高空间) vs 科技板块(低辨识度)

**典型应用**:
> "机器人板块辨识度高,空间想象力足"
> "科技板块太宽泛,辨识度不够"
> "政策支持的板块持续性更好"

**三维度权重与评分细则** (重要补充):

很多人知道"辨识度、持续性、空间想象力",但不知道哪个更重要、怎么打分。需要明确权重和量化标准:

**不同场景下的权重**:

**场景1: 多板块竞争时** (最常见)
问题: 同时出现2-3个热门板块,选哪个?

权重分配:
- **辨识度 (50%)** - 最重要
  * 散户能否快速理解 → 决定参与度
  * 概念是否清晰 → 决定资金能否集中
- **持续性 (30%)** - 次重要
  * 有政策/产业支撑 → 决定周期长度
  * 纯题材炒作1-2周就死
- **空间想象力 (20%)** - 再次要
  * 天花板够高固然好,但没有前两者也白搭

示例:
- 机器人板块: 辨识度9分(清晰) + 持续性8分(政策支持) + 空间7分(AI概念) = 综合得分 8.3
- 科技板块: 辨识度4分(模糊) + 持续性7分(有支撑) + 空间8分(高) = 综合得分 5.9
→ 选机器人板块

**场景2: 周期初期选主线时**
问题: 混沌期结束,哪个板块能成为主线?

权重分配:
- **持续性 (50%)** - 最重要
  * 周期能否持续10天+ → 决定有无参与价值
  * 纯题材炒作3天就结束,没意义
- **辨识度 (30%)** - 次重要
  * 清晰的概念更容易形成板块效应
- **空间想象力 (20%)** - 再次要

示例:
- 政策驱动的新能源: 持续性9分 + 辨识度7分 + 空间8分 = 综合得分 8.3
- 突发事件炒作: 持续性3分 + 辨识度8分 + 空间6分 = 综合得分 5.1
→ 选政策驱动板块

**场景3: 周期末期切换时**
问题: 旧主线退潮,新板块能否接棒?

权重分配:
- **空间想象力 (40%)** - 最重要
  * 新板块要能讲"新故事",否则资金不会切换
- **辨识度 (40%)** - 同样重要
  * 新板块要足够清晰,资金才能快速认同
- **持续性 (20%)** - 次要
  * 周期末期时间紧迫,先看能否启动

示例:
- 新出现的AI应用: 空间9分 + 辨识度8分 + 持续性6分 = 综合得分 7.8
- 老题材重炒: 空间4分 + 辨识度7分 + 持续性5分 = 综合得分 5.3
→ 选新故事

**量化评分标准**:

**辨识度评分** (0-10分):
- 9-10分: 一句话能说清,散户秒懂 (如"机器人""光伏""新能源车")
- 7-8分: 需要简单解释,但容易理解 (如"算力""储能")
- 5-6分: 概念较宽泛,理解成本高 (如"科技创新""数字经济")
- 3-4分: 概念模糊,需要深度解释 (如"新质生产力")
- 0-2分: 完全看不懂,散户无法参与 (如某些专业术语)

**持续性评分** (0-10分):
- 9-10分: 国家级政策+产业趋势 (如"双碳""中国制造2025")
- 7-8分: 部委政策+产业基础 (如"机器人产业规划")
- 5-6分: 地方政策或中等产业逻辑 (如"某省发展规划")
- 3-4分: 事件驱动,无政策支撑 (如"某明星概念")
- 0-2分: 纯题材炒作,无任何支撑 (如"蹭热点")

**空间想象力评分** (0-10分):
- 9-10分: 万亿级市场+颠覆性技术 (如"AI""量子计算")
- 7-8分: 千亿级市场+成长性行业 (如"新能源车""光伏")
- 5-6分: 百亿级市场+传统升级 (如"智能制造")
- 3-4分: 小市场或夕阳行业 (如"某传统行业改造")
- 0-2分: 市场空间极小 (如"小众概念")

**综合决策模板**:
```
步骤1: 根据场景确定三维度权重
步骤2: 对每个板块的三个维度打分(0-10)
步骤3: 计算加权总分 = 辨识度×权重1 + 持续性×权重2 + 空间×权重3
步骤4: 总分>7分 → 优质板块,重点关注
        总分5-7分 → 一般板块,可参与但谨慎
        总分<5分 → 劣质板块,避开
```

**历史案例验证**:

**机器人周期**(2025年某时):
- 辨识度: 9分(概念清晰,人人都懂)
- 持续性: 8分(政策支持+产业升级)
- 空间想象力: 8分(AI+制造业,市场想象力足)
- 综合得分: 8.3分 → 形成大周期(持续20+天)

**科技周期**(某次):
- 辨识度: 4分(概念太宽泛)
- 持续性: 7分(有政策支持)
- 空间想象力: 8分(科技永远是好故事)
- 综合得分: 5.9分 → 周期较短(10天左右就退潮)

**常见误区**:
- ❌ 只看空间想象力: 空间再大,辨识度低也做不起来
- ❌ 三个维度平均权重: 不同场景主要矛盾不同
- ❌ 只看政策: 政策好但概念模糊,散户不参与,起不来
- ❌ 凭感觉打分: 要有量化标准,避免主观

**核心原则**: 
- 短期看辨识度(资金能否快速集中)
- 中期看持续性(周期能否延续)
- 长期看空间(天花板够不够高)
- 多板块竞争时,辨识度是第一筛选标准

### 模型5: 中周期层层递进护航总龙

**描述**:
大周期龙头不是孤立的,背后有多个中周期龙头接力护航,形成"层层递进"的结构。

**结构**:
```
大周期龙(如赛为智能)
  ↑
中周期龙1(如成飞长城) → 中周期龙2 → 中周期龙3
```

**触发条件**:
- 大周期龙出现后
- 判断龙头能否继续时

**运作机制**:
1. 识别大周期龙
2. 观察是否有新的中周期龙接力
3. 有接力 → 大龙安全,可继续持有
4. 无接力 → 大龙孤立,准备撤退

**边界条件**:
- 中周期龙也需要符合龙头标准(10天100%、封板强度)
- 量化时代可能看到"虚假接力"(被扫板)

**跨域验证**:
- 军事战术: 主力突击 + 侧翼掩护
- 产品迭代: 爆款产品 + 系列新品持续热度
- 历史案例: 机器人周期(中毅达破局→成飞长城接力→赛为智能总龙)

**典型应用**:
> "赛为智能能走那么高,因为有成飞长城等中周期龙护航"
> "一旦中周期龙断了,总龙就危险了"

**中周期龙识别标准** (重要补充):

很多人知道要观察中周期龙接力,但不知道怎么识别谁是中周期龙。以下是完整识别流程:

**必要条件** (缺一不可):
1. **板块相关性明确**: 与总龙头同一题材或产业链
   - 例: 机器人周期中,成飞长城(军工机器人)关联赛为智能(工业机器人)
   - 反例: 机器人周期突然出现医药票连板,不算中周期龙

2. **启动时机配合**: 总龙头进入分歧或盘整时启动
   - 总龙头冲高回落时,中周期龙开始发力
   - 形成"你休息我接力"的节奏,维持板块热度

3. **连板强度足够**: 至少3连板以上,最好5板+
   - 2板就死的不算,只是跟风
   - 必须有持续性,能带动板块情绪

4. **市场关注度高**: 成交额放大,龙虎榜游资集中
   - 量能明显放大(相比历史均值3倍以上)
   - 龙虎榜出现知名游资席位

**充分条件** (越多越确定):
5. **形态优于前一个中周期龙**: 高度更高或持续时间更长
   - 前一个中周期龙5板,这个能到7板
   - 或者前一个5天,这个能持续8天
   - 体现"层层递进"特征

6. **带动板块梯队**: 启动后跟风小弟批量跟涨
   - 不是孤立的一只票涨
   - 同板块至少3-5只票跟随上涨

7. **与总龙头共振**: 中周期龙创新高时,总龙头也企稳或反包
   - 两者形成正向反馈
   - 中周期龙强势 → 总龙头获得支撑

**识别流程**:
```
总龙头主升 → 观察期(3-5天) → 有票开始连板 → 判断:

第1天: 是否同题材? 
  → 否: 不是中周期龙,忽略
  → 是: 继续观察

第2-3天: 是否持续3板+?
  → 否: 只是跟风,继续观察其他票
  → 是: 可能是中周期龙候选

第4-5天: 是否带动梯队? 是否与总龙配合?
  → 否: 可能是独立妖股,不算中周期龙
  → 是: 确认为中周期龙

持续跟踪: 这个中周期龙能持续多久? 总龙是否因此延续?
```

**历史参照** (反复研究):
- **机器人周期**: 建设gy(首个中周期龙,3板) → 五洲xc(5板) → 长盛zc(7板) → 襄阳zc(末段)
  * 特征: 一个比一个强,层层递进
  * 结果: 护航赛为智能走出完整大周期

- **化工周期**: 红宝 → 渝SX → 永安YY,轮流护航中毅D
  * 特征: 每个中周期龙启动时,总龙都在盘整
  * 结果: 总龙中毅D完成多阶段主升

**常见误判**:
- ❌ 只看连板数: 有些妖股也能连板,但不在主线板块,不算中周期龙
- ❌ 把跟风票当中周期龙: 跟风票2板就死,无持续性
- ❌ 把补涨票当中周期龙: 补涨票往往在周期末期,不是护航而是衰竭信号

**核心判断**: 中周期龙 = 同题材 + 3板以上 + 时机配合 + 护航总龙完成主升

不是所有连板都是中周期龙,要看是否"护航总龙头完成主升"这个核心作用。

### 模型6: 情绪低点拿先手 / 高点提前撤

**描述**:
在情绪最差时(混沌期冰点)布局先手,在情绪最好时(补涨疯狂)提前撤退。反人性操作。

**触发条件**:
- 低点: 101只指标冰点、跌停数≥7、市场悲观
- 高点: 补涨票疯狂、边缘标的加速、涨停数极值

**运作机制**:
- **低点拿先手**: 小仓试错,等待破局龙
- **高点提前撤**: 不贪最后一波,落袋为安

**边界条件**:
- 低点拿先手≠抄底(还是要等破局信号)
- 高点提前撤≠空仓(可能还有一小波)

**跨域验证**:
- 巴菲特: 别人恐惧我贪婪,别人贪婪我恐惧
- 索罗斯: 盛宴末期提前离场
- 历史案例: 科技周期在2026.1.10高点前撤场

**典型应用**:
> "现在是情绪低点,可以开始观察了"
> "补涨票都疯了,该撤了"
> "不贪最后一口,见好就收"

**时机细化与量化标准** (重要补充):

很多人知道"低点拿先手、高点提前撤",但不知道具体什么时候算低点、什么时候算高点。需要量化标准和具体时机:

**情绪低点拿先手 - 三阶段渐进**:

**第一阶段: 观察期** (满足2项以上进入观察):
- 101只指标 < 30 (连续3天以上)
- 跌停数 ≥ 7 (单日或均值)
- 涨停数 < 20 (市场冷清)
- 封板率 < 50% (封板质量差)
- 市场高度 ≤ 3板 (无强势龙头)
→ 操作: 空仓观望,开始寻找破局龙候选

**第二阶段: 试探期** (满足全部条件开始小仓试错):
- 观察期条件持续5天以上 (确认不是单日偶然)
- 出现10天60-80%异动的票 (接近破局标准,但还未确认)
- 该票无负反馈 (无问询函/无砸盘)
- 有板块逻辑支撑 (新题材/新政策)
→ 操作: 1-2成仓位试错,严格止损(跌破5%立即出)

**第三阶段: 确认期** (满足全部条件加仓):
- 出现10天100%破局龙 (标准达成)
- 破局龙带动板块梯队 (3-5只跟风票上涨)
- 101只指标开始回升 (>40)
- 涨停数开始增加 (>30)
→ 操作: 加仓至5-7成,跟踪破局龙进入主升

**关键**: 低点拿先手≠冰点立即买,而是"观察→试探→确认"三阶段渐进,始终以破局龙出现为核心信号。

**情绪高点提前撤 - 三信号叠加**:

**预警信号** (出现1个提高警惕):
- 涨停数 > 80 (单日极值,历史分位>90%)
- 补涨票开始涨停 (前期不涨的垃圾票突然涨停)
- 市场高度 > 10板 (极端高度,历史少见)
- 101只指标 > 70 (情绪过热)
→ 操作: 停止加仓,密切观察

**撤退信号** (出现2个以上开始减仓):
- 边缘标的连续加速 (板块外围票、妖股疯狂)
- 龙头出现放量滞涨 (成交额放大但不封板)
- 中周期龙断档 (无新中周期龙接力)
- 封板率骤降 (>80%突然降到<60%)
- 跌停数开始增加 (>5个,但涨停数还多)
→ 操作: 减仓50%,落袋为安

**清仓信号** (出现1个立即清仓):
- 龙头跌停 (价格破坏)
- 天道压制信号 (问询函/约谈)
- 补涨票集体炸板 (连续多只补涨票炸板)
- 101只指标骤降 (单日-20以上)
→ 操作: 立即清仓,退潮已开始

**时间维度参考**:
- 混沌期持续时间: 通常5-15天
- 破局到主升: 通常3-7天过渡
- 主升期持续: 通常10-20天
- 补涨到退潮: 通常3-5天
→ 用途: 当周期已进行20天且出现预警信号时,更要警惕

**常见时机误判**:
- ❌ 混沌期第1天就试错: 太早,要等5天以上确认
- ❌ 101只指标刚到40就认为高点: 太早,70+才是高点
- ❌ 看到补涨票涨就撤: 要看是否"疯狂",偶尔补涨是正常的
- ❌ 龙头首次分歧就撤: 分歧是正常的,分歧后再封板是定龙时刻

**量化指标权重** (综合判断用):
```
情绪低点判断权重:
101只指标 (40%) > 跌停数 (30%) > 破局龙出现 (30%)

情绪高点判断权重:
补涨疯狂 (40%) > 中周期龙断档 (30%) > 数据极值 (30%)
```

**历史校准**:
- **2026.1.10科技周期高点**: 101只=75, 涨停数=95, 补涨票疯狂 → 提前撤退成功
- **某次混沌期**: 101只<25持续12天,第8天出现破局龙 → 试探期入场成功

**核心**: 用量化数据框定时机范围,用破局龙/补涨疯狂作为核心确认信号,分阶段渐进操作,不一步到位。

### 模型7: 天道压制优先原则

**描述**:
监管政策(天道) > 一切技术分析和情绪判断。天道压制一出现,无条件退出,不讲道理。

**触发条件**:
- 交易所问询函
- 监管约谈
- 政策打压信号
- 官媒批评

**运作机制**:
1. 识别天道信号(问询函、约谈、政策文件)
2. 立即无条件退出
3. 不做任何侥幸假设

**边界条件**:
- 无法预测天道何时出现
- 出现后的严重程度也难判断
- 只能做到"一出现就跑"

**跨域验证**:
- 风险管理: 黑天鹅事件的无条件止损
- 历史案例: 航天周期(问询函后头铁导致巨亏)、科技周期(提前识别天道压制成功撤退)

**典型应用**:
> "从那之后我发誓绝对不头铁"(航天教训)
> "多点从大局出发理解天道"
> "天道一出,立即退出,不讲道理"

**天道压制信号分级** (重要补充):

很多人知道"天道压制要退出",但不知道哪些信号是真的天道,哪些只是噪音。需要分级识别,避免误判:

**一级警报(红色) - 立即无条件清仓,今日收盘前执行**:
1. **交易所问询函/关注函**: 直接点名某票或某板块异常交易
   - 例: "XX公司收到上交所关注函,要求说明股价异常波动原因"
   - 操作: 持有该票立即清仓,同板块减仓50%以上
   - 历史: 航天周期问询函后头铁导致巨亏

2. **监管约谈**: 证监会/交易所约谈券商/游资/上市公司
   - 例: "监管约谈多家券商,规范两融业务"
   - 操作: 全市场降低仓位至3成以下,观望3-5天
   - 影响: 整体市场情绪会被压制

3. **政策明确打压**: 国家/部委发文打压某行业/某类交易
   - 例: "XX部委发文规范XX行业无序竞争"
   - 操作: 相关板块立即清仓,不抱幻想
   - 持续: 政策打压往往持续数月

4. **官媒点名批评**: 人民日报/新华社/央视点名批评
   - 例: "人民日报评论: 警惕XX概念过度炒作"
   - 操作: 相关板块立即清仓
   - 性质: 官媒发声代表最高层态度

**二级警报(橙色) - 当日减仓50%,次日观察后决定**:
5. **交易所风险提示**: 发布风险提示公告但未问询
   - 例: "交易所提示投资者注意XX板块投资风险"
   - 操作: 减仓50%,次日看市场反应
   - 观察: 如果市场继续强势可能是虚惊,如果转弱立即清仓

6. **券商/机构研报唱空**: 头部券商发布风险警告
   - 例: "XX证券发布报告,认为XX板块估值过高"
   - 操作: 减仓30-50%,提高警惕
   - 判断: 看是单家还是集体唱空,集体唱空更危险

7. **板块内部负面事件**: 龙头公司出现经营问题/财务造假
   - 例: "龙头公司XX被曝财务造假嫌疑"
   - 操作: 该票立即清仓,同板块减仓观望
   - 传导: 负面事件会传导到整个板块

**三级警报(黄色) - 密切观察,暂停加仓,准备撤退预案**:
8. **网络舆情转向**: 社交媒体/财经自媒体开始大规模质疑
   - 例: 大V集体唱空某板块,网络情绪转空
   - 操作: 停止加仓,密切观察1-2天
   - 判断: 可能是噪音,也可能是天道前兆

9. **历史敏感时点**: 重大会议前/敏感日期临近
   - 例: 两会前一周,国庆前一周
   - 操作: 主动降低仓位至5成以下
   - 经验: 敏感时点监管更严格

10. **板块持续异常波动**: 连续多日大幅波动引起关注
    - 例: 某板块连续5天涨停,引发市场热议
    - 操作: 提高警惕,准备撤退预案
    - 前兆: 异常波动往往会引来监管关注

**非天道信号(绿色) - 正常市场行为,不必恐慌**:
- ❌ 单个散户/小V唱空: 噪音,忽略
- ❌ 正常的龙头分歧回调: 技术性回调,不是天道
- ❌ 其他板块的天道压制: 除非系统性监管,否则不影响本板块
- ❌ 自媒体炒作"监管要来": 没有官方信源的消息,不作数

**分级应对策略**:
```
红色警报 → 立即清仓 → 不问原因 → 事后复盘
橙色警报 → 减仓50% → 次日观察 → 决定去留
黄色警报 → 停止加仓 → 密切监控 → 准备预案
绿色(噪音) → 正常持有 → 按原计划 → 不受干扰
```

**判断关键**:
1. **信息源权威性**: 官方>媒体>自媒体>小道消息
2. **针对性强度**: 点名>暗指>泛泛而谈
3. **历史先例**: 同类信号过去的后果如何
4. **市场反应**: 龙虎榜游资是否开始撤退

**常见误判**:
- ❌ 把正常回调当天道: 龙头分歧是正常的,不是天道压制
- ❌ 把自媒体消息当天道: 要看官方信源,自媒体常常夸大
- ❌ 其他板块天道当全局: 除非系统性监管,否则不必全面撤退
- ❌ 忽视黄色警报: 黄色警报虽不紧急,但可能是红色前兆

**航天周期教训**(永远铭记):
- 信号: 交易所问询函(红色警报)
- 反应: 头铁不退,认为"只是形式"
- 结果: 巨亏,龙头跌停
- 教训: "从那之后我发誓绝对不头铁"

**核心原则**: 宁可错杀(虚惊一场),不可漏跑(头铁巨亏)。天道面前,不讲道理,不抱幻想,跑了再说。

## 决策启发式 (Decision Heuristics)

### 启发式1: 不追高,等回调或次日
**场景**: 盘中看到强势票
**快判**: 今天不追,等明天低点或回调再说
**底层逻辑**: 避免情绪化追高,降低成本,提高安全边际

### 启发式2: 封板率<60% + 高度压制,不做接力
**场景**: 龙头封板不稳 + 已有高位板
**快判**: 今天不接力,观望
**底层逻辑**: 接力环境差,风险大于收益

### 启发式3: 跌停数≥7-10,管住手看戏
**场景**: 盘中跌停数≥7
**快判**: 今天不做任何操作,看戏
**底层逻辑**: 市场恐慌,胜率极低

### 启发式4: 涨停数达极值,防范情绪高点
**场景**: 涨停数突破历史高位(如100+)
**快判**: 注意情绪可能见顶,准备减仓
**底层逻辑**: 情绪极致后往往反转

### 启发式5: 混沌期只看不做,或小仓试错
**场景**: 处于混沌期
**快判**: 空仓观察,或1-2成仓试错
**底层逻辑**: 方向不明,降低仓位控制风险

### 启发式6: 破局龙10天100%异动后无负反馈,重点关注
**场景**: 某票10天100%涨幅,且未被打压
**快判**: 这可能是破局龙,列入观察池
**底层逻辑**: 破局龙是周期启动的核心信号

**破局龙识别完整清单** (重要补充):

破局龙是情绪周期从混沌到破局的关键信号,但很多人只知道"10天100%",不知道还要看什么。完整识别需要多维度验证:

**维度1: 价格异动** (必要条件)
- ✅ **10天100%涨幅**: 这是硬指标,低于这个不算破局
  * 计算方法: 从启动日到观察日,累计涨幅≥100%
  * 时间窗口: 10个交易日内完成
- ✅ **连板强度**: 至少3-5连板,最好首板即涨停
  * 弱势拉升(5%、6%慢涨)到100%不算破局龙
  * 要的是强势突破,震撼市场

**维度2: 负反馈检验** (区分真假破局)
- ✅ **无监管打压**: 无问询函、无约谈、无官媒批评
  * 有负反馈 = 假破局,会被天道压制
- ✅ **无市场抛压**: 龙虎榜无大规模出货、无机构砸盘
  * 游资接力是正常的,但不能出现恐慌性抛售
- ✅ **持续性验证**: 冲高后能维持(至少不立即崩盘)
  * 不是一天涨停后就连续跌停
  * 即使回调,也是缩量回调,不是放量暴跌

**维度3: 板块逻辑** (真破局的支撑)
- ✅ **题材新颖度**: 新概念/新政策/新事件驱动
  * 老题材反复炒作很难成为破局龙
  * 市场需要"新故事"才能激发情绪
- ✅ **产业逻辑支撑**: 不是纯题材炒作,有产业基础
  * 例: 机器人政策+产业升级 = 强逻辑
  * 反例: 某某概念日炒一次 = 弱逻辑
- ✅ **板块辨识度**: 概念清晰,市场容易理解
  * "机器人"清晰,"科技创新"模糊
  * 辨识度低的板块很难形成持续情绪

**维度4: 市场位置** (时机验证)
- ✅ **在情绪低点出现**: 混沌期冰点时启动
  * 101只指标<30, 跌停数≥7, 涨停数<20
  * 在情绪高点出现的"异动"往往是妖股,不是破局龙
- ✅ **无竞争龙头**: 同期无其他更强的票
  * 如果同时有3个票都10天100%,要看谁是真龙头
  * 真破局龙会带动板块梯队,不是孤立的

**维度5: 市场共识** (跟随验证)
- ✅ **带动板块梯队**: 同板块跟风票批量上涨
  * 不是只有它一个涨,板块要有联动
  * 至少3-5只同板块票跟涨
- ✅ **游资集中**: 龙虎榜出现知名游资席位
  * 游资嗅觉敏锐,他们的参与是信号
- ✅ **成交额放大**: 量能明显放大(3倍以上)
  * 无量上涨往往是假突破,有量才是真情绪

**识别流程** (按顺序验证):
```
第1天: 发现某票涨停 → 记录启动日

第3-5天: 达到3连板 → 计算涨幅是否≥100%
  → 未达到: 继续观察
  → 达到: 进入验证阶段

验证阶段:
1. 负反馈检验: 有无问询函/约谈/砸盘?
   → 有: 排除,不是破局龙
   → 无: 通过,继续验证

2. 板块逻辑: 题材新吗? 辨识度高吗?
   → 否: 可能是妖股,谨慎
   → 是: 通过,继续验证

3. 市场位置: 在情绪低点出现吗?
   → 否: 可能是末期妖股,谨慎
   → 是: 通过,继续验证

4. 市场共识: 有板块跟风吗? 游资参与吗?
   → 否: 孤立异动,谨慎
   → 是: 确认破局龙

持续跟踪: 破局龙能否进入主升? 有无中周期龙接力?
```

**常见误判**:
- ❌ 只看10天100%: 妖股也能10天100%,但会有负反馈(问询函/砸盘)
- ❌ 在高位出现的异动当破局: 破局龙要在情绪低点出现,高位异动往往是陷阱
- ❌ 孤立上涨当破局: 真破局龙会带动板块,不是孤立的
- ❌ 题材老旧还当破局: 老题材很难激发新情绪,要看题材新颖度

**历史参照** (反复研究):
- **机器人周期的中毅达**: 10天150%,无负反馈,带动机器人板块,在情绪低点出现 → 真破局龙
- **科技周期的某票**: 10天120%,但随即问询函,游资撤退 → 假破局龙(有负反馈)
- **某妖股**: 10天200%,但孤立上涨,无板块跟风,在情绪高点出现 → 妖股,不是破局龙

**核心记住**: 破局龙 = 10天100% + 无负反馈 + 情绪低点 + 板块逻辑 + 市场共识

不是所有"10天100%"都是破局龙,要看是否"破了混沌局面,启动了情绪周期"这个核心作用。

## 执行层补充 (Execution Layer)

> **重要说明**：以下内容基于实战反馈补充的执行细节和使用前提，并非南京路彼岸原文，但与核心方法论兼容。核心方法论解决"懂"的问题，执行层解决"做到"的问题。

---

### 第一层：应用前提条件

在使用这套交易系统前，必须满足以下前提条件，否则所有规则都会失效：

#### 前提1: 资金性质要求

**必须用"无用途、无期限"的闲钱**

❌ **绝不能用的钱**:
- 房款、学费、医疗费等有明确用途的钱
- 3个月内要用的钱（装修、买车、还贷）
- 借来的钱、贷款、信用卡套现
- 家人养老钱、孩子教育基金

✅ **可以用的钱**:
- 3年内不用的闲置资金
- 亏损50%不影响生活质量的钱
- 归零了只是心疼，不会影响家庭的钱

**为什么这是前提**:
> 用有用途的钱交易，你不敢认亏，只能扛、只能赌反弹。所有的止损原则、周期判断都会在"这钱不能亏"的恐惧面前失效。房款进股市，交易规则会自动失效。

**自查问题**:
- 这笔钱亏了50%，你能接受吗？
- 如果明天要用，你能立即取出来吗？
- 亏了这笔钱，家人会跟你翻脸吗？

如果任何一个答案是"不能"或"会"，这笔钱不适合做短线情绪交易。

---

#### 前提2: 决策权归属

**决策权和承担权必须在同一人身上**

❌ **有毒的决策结构**:
- 你判断，她/他承担后果
- 你操作，但钱是家人的
- 你建议，别人执行（或反过来）

这种结构下，"让她/他卖亏了"的心理成本远高于"市场跌了"，你的本能永远选不动。跟判断能力无关，是结构决定的。

✅ **健康的决策结构**:
- 自己的钱，自己决策，自己承担
- 或：家人的钱，但完全授权给你，亏了不能怪你
- 或：联名账户，共同决策，事先约定退出规则

**自查问题**:
- 如果今天止损亏10%，你需要跟谁商量？
- 如果卖了之后涨了，对方会不会埋怨你？
- 如果你坚持要卖，对方不同意，你能强制执行吗？

如果存在"需要征求别人同意才能止损"的情况，这套系统你用不了。

---

#### 前提3: 心理准备

**接受"会亏损、会看错、会踏空"**

✅ **必须接受的现实**:
- 这套系统不保证每次正确，有胜率但不是100%
- 止损是正常的，不是失败，是风控
- 会有看对方向但拿不住的情况
- 会有完美踩空一波大行情的时候

❌ **无法接受这些，就不要用**:
- "我要100%正确，不能亏"
- "止损就是认怂，我不接受"
- "错过一次就想追回来"

**自查问题**:
- 连续止损3次，每次-5%，你会怀疑系统吗？
- 严格止损后，票又涨回来了，你会后悔吗？
- 空仓时看到别人赚钱，你会急着追进去吗？

如果这些情况下你控制不住情绪，先练心态，别急着用这套系统。

---

### 第二层：执行机制（操作细化）

方法论告诉你"应该怎么做"，执行机制告诉你"具体怎么落地"。

#### 机制1: 止损必须程序化

**核心原则：脑子里的止损 = 没有止损**

盘中你的情绪最差、认知能力最弱，这时候做止损决策，100%会被情绪重新谈判掉。

**止损三步执行法**:

**第1步: 盘前设定止损位**
- 买入前就确定止损位（通常是-5%或关键价位）
- 写下来：今天XX票，止损价X.XX元
- 原因：盘前理性，盘中情绪

**第2步: 立即挂条件单**
- 买入后立即挂止损单（条件单或限价单）
- 设置：价格跌破X.XX元，立即卖出
- 原因：机器执行，不给情绪谈判的机会

**第3步: 触发不犹豫**
- 止损单触发 = 立即成交
- 不看"是不是跌得太多了"
- 不想"要不再等等"
- 原因：犹豫 = 更大亏损

**常见逃避话术** (必须警惕):
- ❌ "我就看看，真到止损位我一定走" → 盘中不会走
- ❌ "这个票基本面好，可以不用挂止损" → 情绪票没有基本面
- ❌ "止损位太近，容易被震出来" → 那就别买，不是借口

**刚性规则**: 
> 没挂止损单的持仓 = 违规持仓，必须立即补挂或清仓。

---

#### 机制2: 仓位管理阶梯

**核心原则：满仓 = 丧失决策权 = 只能承受，无法主动**

子弹打完就失去所有主动权。市场跌是在告诉你判断错了，你把它当打折促销越跌越买，这是错上加错。

**三阶段仓位管理**:

**观察期 (1-2成仓位)**
- 触发条件：混沌期，情绪冰点，还没出现破局龙
- 操作：空仓为主，最多1-2成试探
- 目的：保留实力，等待破局信号
- 心态："看不懂就不做"

**试探期 (3-5成仓位)**
- 触发条件：出现破局龙候选（10天60-80%），但还未确认
- 操作：小仓位试错，严格止损（-5%立即出）
- 目的：用小代价测试判断是否正确
- 心态："可以错，但要错得起"

**确认期 (5-7成仓位)**
- 触发条件：破局龙确认（10天100%+带动梯队），进入主升期
- 操作：加仓至5-7成，跟随龙头主升
- 目的：趋势确认后，获取主升段利润
- 心态："趋势明确，持有不动"

**退出期 (降至1-3成或清仓)**
- 触发条件：情绪高点信号、价格破坏、天道压制
- 操作：分批减仓或直接清仓
- 目的：保护利润，避免回吐
- 心态："落袋为安，不贪最后一口"

**永不超过7成仓位**:
- 7成已经是极限
- 留3成机动资金应对突发情况
- 满仓 = 把自己逼到墙角

**仓位纪律**:
```
情况           →  仓位上限  →  原因
看不懂方向     →  2成      →  方向不明，控制风险
试错阶段       →  5成      →  还在验证判断
趋势确认       →  7成      →  最高仓位，留机动空间
任何时候       →  不满仓    →  满仓=丧失主动权
```

#### 机制3: 盘前预案制度

**核心原则：盘中不思考，只执行；盘前做预案，盘中看预案**

盘中是认知能力最差的时段，情绪最激动的时候做决策 = 100%做错。

**盘前预案五问**:

**问题1: 今天市场处于什么周期位置？**
- 混沌/破局/主升/补涨/退潮？
- 7指标数据支持这个判断吗？
- 写下结论：今天是XX期

**问题2: 我的持仓票止损位是多少？**
- 每只票的止损价写清楚
- 立即挂止损单
- 触发条件：价格跌破XX元

**问题3: 今天有什么风险信号要警惕？**
- 天道压制信号（问询函/约谈/政策）？
- 情绪高点信号（补涨疯狂/边缘票加速）？
- 龙头分歧信号（封板率下降）？

**问题4: 今天的操作计划是什么？**
- 持仓票：继续持有/减仓/清仓？
- 观察票：什么条件下买入？
- 空仓时：什么信号出现才出手？

**问题5: 如果出现XX情况，我怎么办？**
- 如果龙头跌停 → 立即清仓，不犹豫
- 如果情绪冰点 → 继续观望，不抄底
- 如果突然拉升 → 不追高，等回调

**预案执行纪律**:
- 盘中只看预案，不做新决策
- 预案外的操作 = 违规操作
- 盘后复盘时，重点看"是否执行了预案"

**核心原则：口头反省 = 没反省；书面记录才能调取**

只在脑子里反省，下次进入同样情绪状态时你调取不出上次的结论。这就是"盘后知道、盘中忘光"的机制。

- 而是"哪一步做错了"（动作）

**记录纪律**:
- 每天盘后必须填写，不能隔天补
- 重点记录"为什么这样操作"，不是记录"涨跌多少"
- 每周回顾一次，看自己是否在重复犯错

### 第三层：心理陷阱警示

以下是实战中最常见的心理陷阱，知道这些陷阱 ≠ 不会掉进去，但至少能快速识别"我掉坑里了"。

#### 陷阱1: 回本心态

**表现**:
- "亏了30%，要涨43%才能回本，太难了，我重仓搏一把"
- "这笔钱亏了，下笔一定要翻倍赚回来"
- "不回本不罢休"

**为什么致命**:
以回本为目标 → 必然重仓 → 必然赌高波动 → 必然亏更多。统计上只有一个结局：亏得更多。

**正确做法**:
1. **接受亏损是沉没成本**: 亏了30%的账户 = 70%本金的新账户
2. **降低仓位重新开始**: 回到观察期（1-2成仓位）
3. **重新评估系统理解**: 为什么会亏30%？哪个环节错了？
4. **设定新的目标**: 目标是"稳定盈利"，不是"回本"

> 回本心态是所有心态问题的总根源。一旦进入回本心态，所有系统都会失效。

---

#### 陷阱2: 成本价锚定

**表现**:
- "都亏20%了，再割不就是傻逼吗？"
- "等回到成本价再卖"
- "套了就拿着，反正不卖就不亏"

**为什么致命**:
市场不知道你的成本价。盯着浮亏做决策，你会永远在最该走的时候走不了。

**正确做法**:
1. **只看价格形态，不看浮亏金额**: 龙头跌破关键位 = 走，不管亏多少
2. **成本价是你的问题，不是市场的问题**: 市场只看供求，不管你多少钱买的
3. **亏损10%止损 > 亏损50%装死**: 止损可以再来，深套可能永远出不来

**自查方法**:
如果你在纠结"亏这么多了"，你已经掉进成本价陷阱了。正确的决策只有一个问题："按当前价格形态，这票该持有还是该卖？"

---

#### 陷阱3: 越跌越买（抄底成瘾）

**表现**:
- "跌了这么多，肯定是底部了"
- "这个价格太便宜了，加仓"
- "跌得越多，我买得越多"

**为什么致命**:
跌是市场在告诉你判断错了，你把它当打折促销。子弹打完 = 失去所有主动权，只能躺平等死。

**正确做法**:
1. **跌 = 错误信号，不是机会信号**: 只有情绪冰点+破局龙出现，才是机会
2. **混沌期不抄底**: "看不懂就不做" > "感觉是底部"
3. **破位立即止损**: 不加仓，只减仓

> 散户亏钱的最大原因：该止损的时候加仓。

---

#### 陷阱4: 盯着自己的盈亏看盘

**表现**:
- 盘中只看自己持仓的涨跌
- 不看大盘情绪、板块强弱
- 涨了开心，跌了痛苦

**为什么致命**:
视野里只剩涨跌，看不到真正重要的信号（周期位置、板块强弱、龙头状态）。

**正确做法**:
**盘中三看顺序**:
1. **先看大盘情绪**: 7指标数据，判断周期位置
2. **再看板块强弱**: 你的板块相对大盘强还是弱
3. **最后看个股**: 你的票相对板块强还是弱

只有做完前两步，才能判断第三步。跳过前两步直接看个股涨跌 = 盲人摸象。

---

#### 陷阱5: 没有预案的盯盘

**表现**:
- 盘中看到什么信号，临时决定怎么办
- "等等看吧"、"再观察一下"
- 关键时刻"脑子一片空白"

**为什么致命**:
没有预案的盯盘 = 在情绪最激动的时候做最重要的决定 = 100%做错。

**正确做法**:
1. **盘前做预案**: 龙头跌停怎么办？封板率降到60%怎么办？
2. **盘中只执行**: 看到预案里的信号 → 立即执行 → 不思考
3. **盘后复盘**: 预案对了吗？执行了吗？

> "脑子一片空白"不是空白，是被恐惧填满了。盘前做预案，盘中就不会空白。

### 第四层：亏损后的操作指南

如果你已经亏损了（比如亏损20%+），以下是重建系统的步骤：

#### 步骤1: 停止交易，强制冷静（3-7天）

**做什么**:
- 清空所有持仓（如果还在扛单，先止损）
- 关闭交易软件
- 不看盘、不复盘、不想股市

**为什么**:
亏损后继续交易 = 情绪驾驶 = 亏更多。必须先让情绪归零。

---

#### 步骤2: 诊断问题根源

**自查清单**:
- [ ] 用了有用途的钱？
- [ ] 决策权不在自己手里？
- [ ] 没有止损或止损没挂单？
- [ ] 满仓或越跌越买？
- [ ] 追高或抄底？
- [ ] 回本心态？
- [ ] 盯着成本价做决策？
- [ ] 不复盘或只复盘结果不复盘动作？

如果超过3个打勾，你的问题不是"看不懂市场"，而是"执行崩溃"。

---

#### 步骤3: 重建系统（降级使用）

**降级方案**:
1. **资金降级**: 只用剩余资金的30%重新开始
2. **仓位降级**: 最高仓位从7成降到3成
3. **周期降级**: 只做主升期确认后的交易，混沌期/破局期全部观望

**目标调整**:
- 不求赚多少，只求"按系统做，能止盈止损"
- 连续10次交易，严格按系统执行，不违规
- 达成后，才能恢复正常仓位

---

#### 步骤4: 强制记录（30天）

**每天必填**:
- 交易日志（前面的模板）
- 违规记录（今天有没有违规操作）
- 情绪记录（今天有没有恐惧/贪婪/后悔）

**30天后复盘**:
- 如果违规次数<3次 → 可以继续
- 如果违规次数≥3次 → 你还没准备好，继续降级
