> **适用范围**：A股短线情绪板块交易
> **核心理念**：数据量化情绪 + 周期定位 + 价格领先 + 风控第一

## 一、核心框架：情绪周期理论

### 1.1 周期四阶段

市场情绪按固定顺序循环，周期必然轮回，但载体和时长不固定。

```
混沌期 → 破局期 → 主升期 → 补涨期 → 退潮期 → 混沌期
```

#### 混沌期
**特征**：
- 上轮周期资金未出清
- 盘面无赚钱效应
- 板块无持续性，分支龙头无高度
- 散户套牢怨气大
- 市场对高度没有共识

**数据表现**：
- 涨停数低位徘徊
- 封板率持续低迷（<60%）
- 连板高度被压制（≤5板）
- 101只指标冰点

**操作策略**：观望为主，或小仓试错，不重仓参与

> "混沌期是彼岸避之大吉的阶段"

---

#### 破局期
**特征**：
- 某票连续超预期，突破10天100%异动线未产生负反馈
- 龙头开始持续顶住兑现压力
- 板块辨识度逐渐清晰

**关键信号**：
- 破局龙抵抗负反馈能力强
- 分歧日（前一天爆量）次日强势封板（弱转强）
- 板块开始出现助攻

**操作策略**：拿先手，情绪低点介入，这是"最后的有性价比上车阶段"

> "一旦确认破局龙出现，就意味着行情可能进入了新周期，为接下来的操作指明方向"

---

#### 主升期
**特征**：
- 龙头确立，主线明确
- 板块画像充分：中军走趋势、连板龙发动情绪、补涨龙提供强度
- 中周期龙层层递进护航总龙头
- 市场情绪持续升温

**数据表现**：
- 封板率>80%
- 连板数高且持续
- 市场高度不断突破
- 溢价率高（>2.5%）
- 涨停数上升但未达极值

**操作策略**：大胆持有，"只要价格未破坏，持有不动"

> "一旦确认主线龙头主升，即使后知后觉也能跟随行情了...做起来容错率是很高的...是要大胆大仓位上车的，不能犹豫"

---

#### 补涨期
**特征**：
- 龙头及中周期龙涨速减缓
- 边缘标的开始疯狂补涨，以连续加速形式完成
- 散户情绪："XX已经涨很多了，我的不可能不会涨"
- 讨论主线的人非常多

**数据表现**：
- 涨停数达到极值高位
- 补涨票批量涨停
- 前排票开始暴量（买盘衰竭）

**操作策略**：准备撤退或直接清仓

> "补涨已经是行情尾声的开始...再参与则容易如散户一般挂在山上"

---

#### 退潮期
**特征**：
- 龙头失去中周期龙护航
- 补涨票快速跌停
- 赚钱效应消失
- 负反馈扩散

**操作策略**：清仓观望，等待下一个周期

> "如再无形成新的中周期龙头，市场维护高度的资金逐渐褪去"

---

### 1.2 大中小周期嵌套

**大周期**：一个完整的题材周期（如机器人周期、化工周期、科技周期）
**中周期**：大周期内由连板龙驱动的波段，每个中周期龙的主升过程
**小周期**：日内情绪波动，龙空龙（龙头到龙头）试错的窗口

**关键规律**：中周期龙层层递进护航总龙头
- 总龙头持续性取决于是否有中周期龙接力
- 中周期龙轮流助攻，维持板块热度
- 一旦无新中周期龙接力 → 周期进入尾声

**历史案例**：
- 机器人周期：建设gy → 五洲xc → 长盛zc → 襄阳zc
- 化工周期：中毅D（总龙）→ 红宝 → 渝SX → 永安YY
- 消费周期：国芳（总龙）→ 国光、华纺、均瑶（中周期）→ 潮宏、万辰（趋势）

> "四者之间层层递进，以自身的强度护航前一个中周期龙头完成双头，最后完成出货"

## 二、量化工具：7指标数据系统

### 2.1 核心指标

每日收盘后必须手动统计，用Excel制作折线图或柱状图观察趋势。

| 指标 | 含义 | 关键阈值 |
|------|------|----------|
| **涨停数 vs 跌停数** | 基础情绪温度 | 跌停≥7-10：管住手 |
| **封板率** | 情绪强度核心指标 | <60%：低点；>80%：高点 |
| **连板数量及趋势** | 市场高度共识 | 持续增加：情绪上升 |
| **涨跌家数比** | 市场面广度 | 三日周期对比看趋势 |
| **市场高度** | 连板最高板数 | 压制or突破的标志 |
| **溢价率** | 昨日涨停今日表现 | >2.5%：高溢价 |
| **101只指标** | 市场热度 | 冰点：观察窗口 |

### 2.2 使用原则

**综合判断，不看单一指标**：
> "指标所处的环境是动态的，使用的时候不能只看数据，还需要结合情绪周期的模型所处何种周期阶段"

**亲手记录，灵感如泉涌**：
> "你一定要亲手做行情记录。你必须亲手填写数字，别让任何人越俎代庖。在亲力亲为的过程中，你会灵感如泉涌"（引用利弗莫尔）

### 2.3 典型组合信号

**可做接力信号**：
- 封板率 > 80%
- 连板数高
- 市场高度不受压制
- 跌停数 < 3

**不做接力信号**：
- 封板率 < 60%
- 市场高度压制5板以下
- 跌停数 ≥ 7-10

**情绪见顶信号**：
- 涨停数达到近期极值
- 封板率极高但补涨票疯狂
- 溢价率开始下降
- 前排票开始暴量

## 三、选股方法：板块画像三维评估

### 3.1 三个维度

**维度1：辨识度**
- 题材是否清晰？
- 龙头是否唯一？
- 与其他板块是否有明确区分？

**维度2：持续性**
- 政策支持周期多长？
- 基本面逻辑能持续吗？
- 资金能持续关注多久？

**维度3：空间想象力**
- 市场对该题材的预期空间有多大？
- 对标历史案例能走到什么高度？
- "高度就是预期"

### 3.2 画像要素

识别周期运营的关键：

**中军**：大市值大容量走趋势，代表大资金介入程度

**连板龙**：发动情绪提供强度
- 一字板：提供强度
- 加速板：突破高度
- 换手板：分歧后确立

**补涨龙**：连续一字提供强度，带动板块梯队

**跟风小弟**：批量模仿赚钱效应

> "板块的画像越充分，能反推板块越强，那么连板龙头的高度就越高，买入时的信心就越充分越安全"

### 3.3 综合判断

- 三者都强 → 大周期潜质 → 大胆上车
- 缺一个 → 中周期 → 谨慎参与
- 缺两个以上 → 小周期或混沌 → 观望

## 四、核心原则

### 4.1 价格领先于情绪

**核心逻辑**：
股价走势先于市场情绪变化，龙头的价格行为是最可靠的信号源。

> "只要价格未破坏，持有不动"

**时间差盈利**：
先知先觉资金（大资金、敏锐游资）→ 价格异动 → 后知后觉资金跟随 → 情绪升温

**实战应用**：
- 在价格已动但情绪未起时介入（拿先手）
- 龙头价格保持强势 → 继续持有
- 龙头价格失守关键位 → 立即退出

**龙头特征**：
> "龙头的一大特征就是强势性，面对兑现，分时强势拉升封板"

### 4.2 情绪低点拿先手，高点提前撤

**反人性操作**：在市场情绪低点（恐惧时）介入，在情绪高点（贪婪时）提前撤退

**拿先手时机**：
- 混沌期末尾，破局信号出现
- 数据显示情绪冰点
- 龙头开始持续超预期

**提前撤退时机**：
- 补涨疯狂阶段
- 散户讨论热烈
- 中周期龙不再接力

**时间差盈利模型**：
```
先手（情绪低点买入）→ 等待 → 主升段（后手追涨推升价格）→ 先手兑现离场
```

> "后手提前兑现先手"

| # | 规则 | 触发条件 | 快速判断 |

**第一优先级（硬约束）**：
- 天道压制 → 立即退出

**第二优先级（周期定位）**：
- 混沌期 → 观望
- 破局龙信号 → 重点跟踪
- 定龙时刻 → 大胆上车

**第三优先级（日常操作）**：
- 不追高

- 看A做B

**第四优先级（退出信号）**：
- 涨停数极值
- 无中周期龙接力
- 补涨疯狂

## 六、风险控制体系

### 6.1 天道压制优先原则（最高优先级）

**决策优先级铁律**：
```
监管/政策信号 > 技术信号 > 数据信号 > 个人判断
```

**天道压制信号**：
- 监管层面表态
- 政策导向转变
- 媒体定调批评
- 交易所问询函

**执行原则**：
一旦出现"天道压制"，无条件退出，不存在博弈空间

> "从那之后我发誓绝对不头铁"（航天周期教训）

> "多点从大局出发理解天道，对我们长期活在市场里，是有好处的"

### 6.2 快速止损机制

**心态**：
> "大不了就是一割嘛"

**原则**：
- 龙头价格破位 → 立即止损
- 中周期龙不接力 → 准备撤退
- 补涨疯狂 → 提前离场
- 不死扛，不执念

### 6.3 仓位管理

**周期配置**：
- 混沌期：观望或小仓试错
- 破局期：拿先手，适中仓位
- 主升期：大胆持有，"交易就自随心了"
- 补涨期：准备撤退
- 退潮期：清仓离场

**反模式**：
- ❌ 混沌期重仓
- ❌ 情绪高点ALL IN
- ❌ 追涨杀跌
- ❌ 贪婪不止盈

## 七、量化时代适应策略

### 7.1 市场环境变化

**观察到的现象**（2026年）：
- 慢牛要求下，趋势逐渐成为主流形式
- 量化策略转变：减少板块平铺拉高潮，增加强趋势个股反复推进
- "破5日线甚至10日线的情况...为什么又能次日拉起来反复反包又新高"

### 7.2 适应性调整

**看A做B策略**：
- 看强势板块（研究方向）
- 买低吸标的（实际操作）
- 避免被量化日内收割

**拉长持有周期**：
- 从日内追涨杀跌 → 中周期持有
- 对不断新高的个股："分时上的低点，就会因为不断新高的预期而被不同的a、b、c力量接力"

**核心理念不变**：
> "只有适应我们才能赚超额"

## 八、完整决策流程

### 8.1 每日工作流

1. **收盘后统计7指标数据**
   - 手动记录Excel
   - 绘制折线图观察趋势

2. **判断情绪周期位置**
   - 混沌/破局/主升/补涨/退潮？
   - 结合数据验证

3. **检查天道压制信号**
   - 政策新闻
   - 监管表态
   - 媒体定调

4. **跟踪板块画像**
   - 中军表现
   - 中周期龙接力情况
   - 补涨票动向

5. **制定次日策略**
   - 观望/拿先手/持有/撤退？
   - 应用12条启发式快速判断

### 8.2 决策树

```
1. 是否有天道压制信号？
   → 是：立即退出，不问盈亏
   → 否：继续

2. 当前处于什么周期？
   → 混沌期：观望或小仓试错
   → 破局期：拿先手
   → 主升期：大胆持有
   → 补涨期：准备撤退
   → 退潮期：清仓观望

3. 数据指标是否支持？
   → 封板率<60% + 高度≤5板：不做接力
   → 跌停数≥7：管住手
   → 封板率>80% + 连板数高：可做接力

4. 龙头价格行为如何？
   → 价格强势：继续持有
   → 价格破位：止损离场

5. 中周期龙是否接力？
   → 有新接力：继续持有
   → 无新接力：准备撤退
```
