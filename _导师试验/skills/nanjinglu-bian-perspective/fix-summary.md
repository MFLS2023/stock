- 识别流程图 (5天观察期)

#### 5. 天道压制信号需要分级 → 已添加四级预警系统
**位置**: 模型7 (天道压制优先原则) 后
**新增内容**: "天道压制信号分级"
- 红色警报 (4种): 问询函、监管约谈、政策打压、官媒批评 → 立即清仓
- 橙色警报 (3种): 风险提示、机构唱空、负面事件 → 减仓50%
- 黄色警报 (3种): 舆情转向、敏感时点、异常波动 → 停止加仓
- 绿色(噪音): 散户唱空、正常分歧、其他板块天道 → 忽略
- 分级应对策略 + 判断关键 + 航天周期教训

- 时间维度参考 (各阶段典型持续时间)
- 量化指标权重 (低点判断、高点判断)

## 用户体验改进

### 新手友好度提升
1. **不再僵化执行阈值**: 明确"相对阈值优先于绝对阈值"，避免机械操作
2. **有冲突解决指南**: 不再困惑于"价格说持有,情绪说撤退"的矛盾
3. **识别标准可落地**: 破局龙/中周期龙从"感觉"变为"5步验证流程"
4. **天道分级降低误判**: 不再把正常回调当天道,也不再忽视真正的危险信号

### 专家级深度增强
1. **场景化权重分配**: 不同周期看不同指标,抓住主要矛盾
2. **量化评分体系**: 板块画像从定性变为定量(0-10分标准)
3. **历史案例验证**: 每个新增部分都有真实案例佐证
4. **常见误区警示**: 每个关键部分都标注"❌不要这样做"
