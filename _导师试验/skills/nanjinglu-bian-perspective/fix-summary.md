## 修复清单

### 9. 案例不够具体 → 补充判断依据与数据来源

**位置**: 启发式 1、2、3、8

不是简单加案例,而是把"结论"拆成"依据 + 数据从哪来 + 怎么验证":

- **启发式1**: 新增"什么算追高"三特征定义(相对涨幅 / 买入理由 / 有无止损位),
  以及三类例外的完整前置条件
- **启发式2**: 新增"为什么不能被其他信号对冲",说明封板率是唯一直接测量
  接力资金意愿的指标
- **启发式3**: 新增"为什么'我的票好好的'不算例外",讲清恐慌 1-3 天的传导链条
- **启发式8**: 每一步都标注了 MCP 数据来源(`get_zt_pool_detail`、`get_stock_reason`、
  `get_yesterday_zt`、`get_ladder`、`get_lhb_dept`),从"抽象判断"变成"查哪个接口看哪个字段"

### 10. 量化时代策略不够深 → "看A做B"五步操作指南

**位置**: 启发式8

原文只有 3 行(场景/快判/底层逻辑),现扩为完整方法:

- **第1步 识别 A 板块**: 量化占据的 5 个痕迹(秒板薄封单、反复炸板回封、
  归因泛化、梯队断层、龙虎榜无游资),每条给数据来源
- **第2步 判断虚高还是真启动**: 5 项对照表(次日溢价 / 梯队 / 封单 / 游资 / 归因)。
  **A 是真启动时这条启发式不适用**,直接做 A
- **第3步 找 B**: B 的三种合法来源(产业链上下游 > 同题材低位分支 > 历史流向),
  以及 B 必须同时满足的 4 个硬条件
- **第4步 执行节奏**: A 给信号 B 下单的完整对应表。关键点: **B 的买卖信号来自 A,
  不来自 B 自己的走势**
- **第5步 何时放弃**: 4 种失效情形
- **边界声明**: 明确这是适应性调整,2026 年前无历史样本,看不懂就退回启发式 5

### 11. 反模式与正模式关联弱 → 建立双向映射表

**位置**: 反模式章节整体重写

15 条从平铺列表改为四列映射表: 反模式 → 具体表现 → 对应正面原则 → 触发时立即做什么。
另新增"反模式的共同结构",把 15 条归并为 3 类根源:

```
系统缺位   (1、8、11、12)        → 建立数据系统 + 书面复盘
情绪主导   (4、6、7、14、15)      → 周期定位 + 仓位阶梯 + 止损挂单
拒绝坏消息 (2、3、5、9、10、13)   → 天道优先 + 承认边界
```

自查用法也改了: 亏损后不问"我为什么亏",问"我掉进了哪几条反模式";
命中超 3 条说明问题在执行不在判断,转执行层第四层。

### 12. 诚实边界过于谦虚 → 新增"擅长领域"分级

**位置**: 诚实边界章节开头

先加一段开场说明: 边界说明的作用是划定"该来问我什么",不是自我否定,
两句话都得当真。然后按星级列出 8 个擅长领域:

- ★★★★★: 情绪周期定位、风险信号分级应对、该不该动手的即时判断
- ★★★★☆: 破局龙与中周期龙识别、板块画像评估、执行层诊断
- ★★★☆☆: 量化时代适应策略(无历史样本)、具体票形态解读(不预测下一步)

"我能做什么"也补了一条: 诊断执行问题(对照 15 条反模式和执行层四层)。
