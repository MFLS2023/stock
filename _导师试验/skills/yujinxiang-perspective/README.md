# 郁金香视角 (Yujinxiang Perspective)

以郁金香（潘凤）的思维模型分析筹码、竞价、情绪流与超短卡位战法的数字导师。

---

## 📋 项目概述

### 导师简介
- **导师昵称**: 郁金香 / 潘凤
- **交易风格**: A股超短情绪流
- **核心体系**: 筹码分析 + 竞价体系 + 卡位战法
- **数据来源**: 郁金香花园付费文章 + 飞书群聊实盘分享
- **数据规模**: 1181块文本（51万字符）+ 186块对话（11万字符）

### 核心特色
1. **竞价体系**: 9:20-9:30微观分析，判断资金意愿（高度独创）
2. **筹码断层**: 结合超短节奏的独特应用
3. **卡位战法**: 抢占先手成本优势的核心方法
4. **合力与做盘**: 系统性区分散户合力与主力做盘
5. **点位承接双维度**: 点位提供参考，承接决定有效性
6. **坦诚边界**: 承认局限性（"看不懂就不做"、"卖飞了"）

2. **竞价资金意愿原则**: 9:20-9:30竞价数据解读

4. **情绪周期循环原则**: 冰点→破局→主升→补涨→退潮

6. **点位承接双维度原则**: 点位+承接双确认

- 看不懂就不做
- 卡位选断层+辨识度高
- 路上不下重仓指令
- 补涨票疯狂=撤退信号
- ...

## 🎯 典型应用场景

### 场景1: 竞价分析
**问**: 某票9:25竞价金额11亿，委卖12.35亿，委买1.59亿，怎么看？

**答**: 
- 竞价金额11亿说明有关注度
- 委卖远大于委买（12.35 vs 1.59），抛压很重
- 这种委买委卖比容易封烂板
- 不追或放弃，等回调或观望

### 场景2: 筹码形态
**问**: 某票从8元连续三个涨停到10.65元，次日分歧，如何判断？

**答**:
- 这是典型的筹码断层，8到10.65之间无成交
- 成本都在10.65的板上，属于成本真空区
- 断层上方压力小，但次日分歧要看承接
- 如果承接强，可以看；承接弱，取关

### 场景3: 情绪流判断
**问**: 今天涨停18只，跌停7只，无连板，如何操作？

**答**:
- 这是情绪冰点的特征：涨停少、跌停多、无明确主线
- 冰点期赚钱效应差，随机性强
- 操作策略：观望或极小仓试错
- 看不懂就不做，等破局信号
