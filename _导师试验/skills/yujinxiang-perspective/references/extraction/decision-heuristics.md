# Phase 2.2: 决策启发式提取

**定义**: 快速判断规则，在特定场景下的即时反应模式

---

## 启发式1: 竞价承接弱不追
**场景**: 竞价阶段观察到委卖远大于委买
**快判**: 不追高，等回调或放弃
**底层逻辑**: 
- 竞价是资金意愿最真实表达
- 委卖压力大说明抛压重
- 易封烂板或开盘跳水
**案例**: 海南华铁竞价委卖12.35亿 vs 委买1.59亿 → 封烂板

---

## 启发式2: 开盘直线下无承接不接
**场景**: 开盘后分时一根直线下来，盘口无挂单
**快判**: 不接，观望
**底层逻辑**:
- 大资金在出货且市场无法承接
- 缺少潜在关注盘
- 容易情绪杀到跌停
**案例**: 海南华铁2.17早盘低点，承接太弱 → 取关

---

## 启发式3: 日内最低点破位即走
**场景**: 合力票当日最低点被跌破
**快判**: 立即止损
**底层逻辑**:
- 合力票靠市场共识支撑
- 破位说明共识破裂
- 容易引发踩踏
**案例**: 常山北明2.28破昨日最低点 → 杀到跌停

---

## 启发式4: 情绪冰点只看不做或小仓试错
**场景**: 涨停数<20，跌停数>5，无明确主线
**快判**: 观望或极小仓位试错
**底层逻辑**:
- 情绪冰点赚钱效应差
- 板块无共识，个股涨跌随机性强
- 小仓试错可寻找破局龙
**案例**: "市场情绪冰点，看不懂就不做"

---

## 启发式5: 看不懂就不做
**场景**: 无法用筹码+竞价+情绪流推演次日走势
**快判**: 不参与
**底层逻辑**:
- 模式外盈亏都是运气
- 保护本金是第一位
- 只在能力圈内赚钱
**案例**: 做盘票、复杂题材、异常走势

---

## 启发式6: 卡位选筹码断层+板块辨识度高
**场景**: 9:20-9:25卡位选标
**快判**: 优选当日断层 + 板块龙头 + 辨识度高的标的
**底层逻辑**:
- 断层 = 压力小，易持续
- 板块辨识度高 = 容易引发市场共识
- 龙头 = 资金最先关注
**案例**: "我当时买三孚就是这个扩产逻辑"

---

## 启发式7: 合力票看分时堆量+盘口挂单
**场景**: 判断合力票承接强度
**快判**: 
- 分时堆量 + 盘口有单 = 强承接，可参与
- 分时无量 + 盘口无单 = 弱承接，回避
**底层逻辑**:
- 合力票靠散户资金
- 堆量说明市场意愿
- 盘口挂单说明接盘意愿
**案例**: 海南华铁2.12有承接 vs 2.17无承接

---

## 启发式8: 做盘票看不懂就不做
**场景**: 怀疑标的是做盘票
**快判**: 不参与
**底层逻辑**:
- 做盘票盘口可作假
- 主力可随时砸盘
- 散户处于信息劣势
**案例**: "做盘的单子可以作假，没有参考意义"

---

## 启发式9: 路上不下重仓指令
**场景**: 在移动中、非冷静环境
**快判**: 不做重大决策，等回到完整分析环境
**底层逻辑**:
- 重仓需要冷静完整的分析
- 移动中容易冲动
- 环境影响决策质量
**案例**: "周四中午还想梭哈兆易创新 还是在路上没敢动"

---

## 启发式10: 补涨票疯狂+边缘标的加速=撤退信号
**场景**: 情绪周期末期，边缘标的开始涨停
**快判**: 准备撤退，不追涨
**底层逻辑**:
- 补涨期是情绪周期尾声
- 边缘标的涨停说明散户疯狂
- 龙头即将分歧
**案例**: 情绪流退潮期描述

---

## 启发式11: 竞价金额大+锁筹=强势，日内看高
**场景**: 竞价阶段观察到大额竞价且委买远大于委卖
**快判**: 强势标的，日内看高，拐点不破是看点
**底层逻辑**:
- 大额竞价说明市场关注度高
- 锁筹说明惜售，供需失衡
- 急拉后回踩不破说明强势
**案例**: 利欧股份2024.12.5竞价锁筹 → 开盘急拉 → 拐点不破是看点

---

## 启发式12: 市场共识票+超预期=正预期差机会
**场景**: 情绪冰点中，市场共识票表现超预期
**快判**: 关注，日内最低点不破可参与
**底层逻辑**:
- 市场预期低 → 实际表现好 = 正预期差
- 容易引发关注和资金介入
- 但市场共识票也容易踩踏，要快速止损
**案例**: 常山北明2.27情绪冰点中红盘震荡

---

## 启发式13: 牛市浮盈大勿频繁止盈
**场景**: 牛市中，持股浮盈较大
**快判**: 不要因为浮盈大就提前止盈（反面教训）
**底层逻辑**:
- 牛市趋势未破不要轻易下车
- 老手频繁切换反而跑输新手
- "要先被套住就拿住了"
**案例**: 2026年6月频繁卖飞澜起、三孚的反思

---

## 启发式14: 两周满仓需休息
**场景**: 持续高仓位运作两周以上
**快判**: 主动降低仓位，休息调整
**底层逻辑**:
- 高仓位带来心理压力
- 持续盯盘导致失眠焦虑
- 休息后决策质量更高
**案例**: "两周满仓了 休息一下了"

---

## 启发式15: 点位+承接双确认
**场景**: 标的接近潜在支撑位
**快判**: 
- 点位到 + 承接强 = 可参与
- 点位到 + 承接弱 = 回避
**底层逻辑**:
- 点位只是参考位
- 承接决定点位有效性
- 两者必须同时确认
**案例**: 所有点位承接案例

---

## 快速决策树

```
遇到交易机会时：
├─ 能用体系推演吗？
│  ├─ 否 → 启发式5: 不做
│  └─ 是 → 继续
│
├─ 情绪周期位置？
│  ├─ 冰点 → 启发式4: 只看不做
│  ├─ 破局/主升 → 继续
│  └─ 补涨/退潮 → 启发式10: 准备撤退
│
├─ 资金性质？
│  ├─ 做盘票 → 启发式8: 不做
│  └─ 合力票 → 继续
│
├─ 竞价承接？
│  ├─ 弱 → 启发式1: 不追
│  └─ 强 → 继续
│
├─ 开盘走势？
│  ├─ 直线下无承接 → 启发式2: 不接
│  └─ 有承接 → 继续
│
├─ 点位+承接？
│  ├─ 双确认 → 启发式15: 可参与
│  └─ 任一弱 → 回避
│
└─ 持有中破位？
   └─ 是 → 启发式3: 立即止损
```
