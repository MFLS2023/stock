# Phase 2.1: 心智模型提取（三重验证）

**提取标准**:
1. **跨域出现**: 在≥2个不同场景/案例中验证
2. **预测能力**: 能预测未来行为和结果
3. **排他性**: 与其他模型有明确区分

---

## 模型1: 筹码真实成本原则

### 描述
股票的真实筹码分布来自历史成交记录，不是软件算法推测。通过识别K线形态判断成本区间类型。

### 触发条件
- 分析个股时，首先看历史K线形态
- 识别密集区、断续区、断层区

### 运作机制
1. **密集区**: K线长期横盘 → 大量筹码在此区间 → 该区域是天然支撑/压力
2. **断续区**: 台阶式涨跌 → 筹码分布在多个台阶 → 多重支撑/压力
3. **断层区**: 连续涨停/跌停 → 中间无成交 → 成本真空，压力小

### 边界条件
- 只适用于有明显K线形态的标的
- 超短周期内筹码意义减弱
- 庄股、做盘票的筹码不可信

### 跨域验证
- **验证1**: 海南华铁当日断层 → 成本在板上 → 次日震荡有承接（2025.2.11-12）
- **验证2**: 所有超短案例都先看筹码形态
- **验证3**: 与点位判断结合，筹码密集区是天然支撑

### 典型应用
> "海南华铁2.11属于当日断层，这种合力票，当日去接的成本都在2.11的板上"
> "筹码密集区是天然支撑位"

## 模型2: 竞价资金意愿原则

### 描述
9:20-9:30竞价阶段是超短资金意愿的最真实表达，通过竞价金额、委买委卖比、竞价形态判断全天走势。

### 触发条件
- 每日9:20开始观察
- 关注竞价金额、委买委卖、大单流向

### 运作机制
1. **竞价金额**: 反映市场关注度，金额越大越受关注
2. **委买委卖比**: 
   - 委买远大于委卖 → 锁筹，可能急拉
   - 委卖远大于委买 → 抛压大，易烂板
3. **竞价形态**: 
   - 早期快速拉升 → 强势，日内看高
   - 持续下压 → 弱势，日内看低
4. **竞价承接**: 竞价金额与委买委卖的动态平衡

### 边界条件
- 只适用于有一定流动性的标的
- 做盘票竞价可作假
- 特殊事件（如公告）会扭曲竞价

### 跨域验证
- **验证1**: 海南华铁竞价金额11亿，委卖12.35亿，委买1.59亿 → 封烂板（2025.2）
- **验证2**: 利欧股份竞价锁筹 → 开盘急拉 → 向下拐点不破就是看点（2024.12.5）
- **验证3**: 常山北明竞价低开破昨日最低点 → 开盘向下 → 当天杀到跌停（2025.2.28）

### 典型应用
> "竞价也是最能代表超短资金意愿的一个环节了"
> "竞价金额11亿之后，竞价结束的委卖12.35亿，委买只有1.59亿，所以封了烂板"

## 模型3: 卡位先手优势原则

### 描述
超短交易中，在9:20-9:25提前挂单锁定目标，可获得成本优势和心理优势。卡位成功的前提是正确判断情绪流和筹码形态。

### 触发条件
- 情绪流处于破局期或主升期
- 目标标的符合：筹码断层 + 板块辨识度高 + 竞价承接好
- 9:20-9:25时间窗口

### 运作机制
1. **提前判断**: 前一晚或当日早盘前完成标的筛选
2. **卡位挂单**: 9:20-9:25挂单，抢占先手
3. **成本优势**: 比开盘后追高成本低
4. **心理优势**: 提前锁定，减少盘中纠结

### 边界条件
- 只适用于情绪流适合的阶段（破局期、主升期）
- 情绪冰点或退潮期不卡位
- 模式外标的不卡位

### 跨域验证
- **验证1**: 与情绪流结合 → 只在破局期和主升期卡位
- **验证2**: 与筹码分析结合 → 优选断层标的
- **验证3**: 与竞价体系结合 → 竞价承接确认后加码或止损

### 典型应用
> "9:20-9:25卡位"
> "我周四中午还想梭哈兆易创新的 都思考了半天 还是在路上没敢动"（反面案例：不在路上下重仓）

## 模型4: 情绪周期循环原则

### 描述
市场情绪按"冰点→破局→主升→补涨→退潮→冰点"循环，每个阶段有明确特征和操作策略。

### 触发条件
- 每日观察涨停数、跌停数、连板数、封板率
- 结合板块轮动和龙头表现

### 运作机制
1. **冰点期**: 涨停<20，跌停>5，无明确主线 → 观望或小仓试错
2. **破局期**: 某板块出现连板龙头 → 关注，寻找卡位机会
3. **主升期**: 龙头持续走强，板块共振 → 持有不动，只要价格未破坏
4. **补涨期**: 边缘标的加速，散户疯狂 → 准备撤退
5. **退潮期**: 龙头分歧，补涨票跌停 → 空仓或极小仓观察

### 边界条件
- 天道压制可打断任何阶段
- 量化时代周期可能拉长
- 需要结合具体数据判断，不能机械套用

### 跨域验证
- **验证1**: 常山北明案例 → 情绪冰点中的预期差（2025.2.27）
- **验证2**: 海南华铁案例 → 破局后的持续验证（2025.2）
- **验证3**: 与南京路彼岸的情绪周期框架相通（跨作者验证）

### 典型应用
> "情绪冰点，常山北明红盘震荡，日内最低点不破就是看点"
> "市场都在老登"（情绪退潮期）

## 模型5: 合力与做盘区分原则

### 描述
市场资金分为散户合力和主力做盘，通过分时形态、换手率、盘口特征区分。不同资金性质对应不同操作策略。

### 触发条件
- 分析个股时，首先判断资金性质
- 看分时形态、成交量、盘口挂单

### 运作机制
**合力票特征**:
- 分时堆量（锯齿状）
- 高换手率
- 大单净额有参考意义
- 点位来自市场共识

**做盘票特征**:
- 分时对敲（规律性拉升打压）
- 低换手率，筹码锁定
- 盘口可作假，大单净额无意义
- 点位看主力成本

**操作策略差异**:
- 合力票：看市场承接，破位即走
- 做盘票：看不懂就不做，模式外

### 边界条件
- 合力票也可能转为做盘票（主力介入）
- 做盘票也可能转为合力票（主力退出）
- 需要动态判断，不是一次性标签

### 跨域验证
- **验证1**: 海南华铁 → 合力票，看分时堆量和盘口承接
- **验证2**: 利欧股份 → 合力票锁筹模型
- **验证3**: 与点位判断结合 → 合力票看市场共识位，做盘票看主力成本

### 典型应用
> "如果是合力票，还可以看大单净额。但仅限合力票，做盘的单子可以作假，没有参考意义"
> "合力票点位是怎么形成的？很简单，市场共识"

## 模型6: 点位承接双维度原则

### 描述
点位不是绝对支撑，必须结合承接强度动态判断。点位提供参考位，承接决定有效性。

### 触发条件
- 标的接近潜在支撑位时
- 观察日内分时承接、盘口挂单、五分K堆量

### 运作机制
1. **点位识别**:
   - 分时点位：日内高低点
   - 日K点位：前期密集区、缺口、关键价位
   - 五分钟点位：更细致的支撑压力

2. **承接判断**:
   - 强承接：分时堆量 + 盘口挂单 + 五分K集中
   - 弱承接：开盘直线下 + 盘口无单 + 散乱成交

3. **动态决策**:
   - 点位 + 强承接 = 看点
   - 点位 + 弱承接 = 取关点

### 边界条件
- 合力票和做盘票的点位意义不同
- 短线和趋势的点位粒度不同
- 5日线、10日线不是绝对支撑，只是恰好落到上面

### 跨域验证
- **验证1**: 海南华铁2.12 → 杀到地板有承接 → 看点；2.17 → 无承接 → 取关
- **验证2**: 常山北明2.27 → 日内最低点不破 → 看点；2.28 → 破位 → 取关
- **验证3**: 拓维信息 → 十字星低点形成市场共识点位

### 典型应用
> "点位，则是辅助判断承接的最重要方法"
> "日内最低点不破，就是看点；破了，就是取关点"
> "承接，即代表了市场预期"

## 模型7: 模式内代入边界原则

### 描述
只在自己体系能理解、能推演的模式内操作。模式外的机会再好也不碰，承认能力圈边界。

### 触发条件
- 遇到任何交易机会时
- 问自己：能用筹码+竞价+情绪流推演吗？

### 运作机制
**模式内判断标准**:
1. 筹码形态清晰（密集区/断续区/断层区）
2. 竞价数据可解读（金额、委买委卖）
3. 情绪流位置明确（冰点/破局/主升/补涨/退潮）
4. 能推演次日走势

**模式外特征**:
- 看不懂筹码形态
- 竞价异常无法解释
- 情绪流位置不明
- 无法推演次日走势

**操作原则**:
- 模式内 → 可参与
- 模式外 → 坚决不碰
- 模式内亏损可接受，模式外盈亏都是运气

### 边界条件
- 模式会随着认知升级而扩大
- 牛市vs熊市，模式可能不同
- 体系外不代表标的不好，只代表自己看不懂

### 跨域验证
- **验证1**: 与风险控制结合 → 模式外不亏钱
- **验证2**: 与情绪流结合 → 不同情绪阶段模式不同
- **验证3**: 与自我认知结合 → 承认局限性，"看不懂就不做"

### 典型应用
> "模式内代入"（反复强调）
> "看不懂就不做"
> "体系内/体系外"

## 三重验证总结

| 模型 | 跨域出现 | 预测能力 | 排他性 |
|------|---------|---------|--------|
| 筹码真实成本 | ✅ 多案例 | ✅ 预测支撑压力 | ✅ vs软件筹码 |
| 竞价资金意愿 | ✅ 多案例 | ✅ 预测全天走势 | ✅ vs开盘后判断 |

| 合力做盘区分 | ✅ 多案例 | ✅ 预测资金行为 | ✅ vs不区分资金性质 |
| 点位承接双维度 | ✅ 多案例 | ✅ 预测支撑有效性 | ✅ vs单看点位 |
| 模式内代入 | ✅ 跨场景 | ✅ 预测风险可控性 | ✅ vs机会主义 |
