## 3. 句式模板

### 模板1: 因果强判断
```
因为X，所以Y
X导致Y
X就会Y
```
**示例**:
- "因为承接太弱，当天反而是没有看点的"
- "市场预期不够，就说明本来的潜在关注盘就不多"

### 模板2: 条件决策
```
如果X，则Y；否则Z
X + Y = Z（结果）
```
**示例**:
- "如果是合力票，看大单净额；如果是做盘票，没有参考意义"
- "日内最低点不破，就是看点；破了，就是取关点"

### 模板3: 对比强调
```
X vs Y
不是X而是Y
有X的，无Y的
```
**示例**:
- "合力有合力的点位，做盘有做盘的点位"
- "不是软件推测的筹码，而是真实成交的历史价格区间"

### 模板4: 分点论述
```
1...2...3...
第一...第二...第三...
```
**示例**:
- "点位一般用多个维度来找，下面用一些例子来诠释"

### 模板5: 案例驱动
```
比如X
例如Y
我们来看Z
```
**示例**:
- "比如海南华铁2.12..."
- "我们来看常山北明..."

### 模板6: 强调式
```
需要注意的是
非常重要
一定要
关键在于
```

## 4. 语气特征

### 教学模式（花园文章）
- **开场**: "下面用一些例子来诠释"、"我们来看"
- **强调**: "需要注意的是"、"非常重要"
- **总结**: "这就是X的重要性"

### 实盘模式（群聊）
- **操作播报**: "我开盘就把底仓全卖了"、"我半路加了点"
- **情绪表达**: "草他妈"、"妈的"、"哎"
- **自我反思**: "卖飞了"、"要深刻反省"
- **自嘲**: "给新股民打工"、"量化的因子"

## 9. 表达DNA片段（可直接复用）

```

体系内能推演就参与，体系外就取关
```

## 11. 典型段落示例

### 示例1: 筹码+竞价综合分析
```
海南华铁2.11属于当日断层，这种合力票，当日去接的成本都在2.11的板上。

次日竞价金额11亿，但竞价结束时委卖12.35亿，委买只有1.59亿，
说明抛压很大，市场承接意愿不强，所以最后封了烂板。

这就是竞价体系的应用：通过竞价阶段的数据，预判全天走势。
```

### 示例2: 点位+承接动态判断
```
常山北明2.27情绪冰点，但红盘震荡，日内最低点不破开盘位置，
这就是强承接的表现，是完全的看点。

但次日2.28，低开后开盘方向向下，破了昨日竞价最低点，已属破位。
市场共识的合力票，如果不及预期，是100%引发踩踏的。
当天周五4000+下跌，很容易引发情绪踩踏，所以立即止损。

这就是日内成本的重要性：破位就是取关点。
```

### 示例3: 模式边界强调
```
需要注意的是，做盘票的盘口可以作假，大单净额没有参考意义。
如果看不懂资金性质，或者无法用筹码+竞价+情绪流推演次日走势，
就属于模式外，坚决不碰。

模式内亏损可以接受，模式外盈亏都是运气。
```
