## 1. 核心决策案例

### 案例1: 海南华铁 - 合力票承接判断
**时间**: 2025年2月
**决策链**:

**Day 1 (2.11)**: 
- **观察**: 当日断层
- **分析**: 成本都在板上，属于合力票
- **决策**: 关注，未明确操作

**Day 2 (2.12)**:
- **观察**: 中午杀到接近地板，但午后迅速拉回
- **分析**: 
  - 五分K堆量在同一区域 → 有承接资金
  - 日内分时堆量 → 合力分时
  - 盘口有挂单 → 承接有效
- **决策**: 认为有看点（推断可参与）

**Day 3-6 (2.13-2.16)**: 
- **观察**: 持续震荡
- **分析**: 承接持续有效
- **决策**: 持有或观察

**Day 7 (2.17)**:
- **观察**: 早盘低点，但承接太弱
- **分析**:
  - 开盘一根直线下来 → 无承接
  - 盘口无挂单 → 市场预期不够
  - 虽然是低点趋势池子，但承接决定一切
- **决策**: 取关，不参与

**决策框架提炼**:
```
合力票 = {
  IF (日内分时堆量 AND 盘口有承接 AND 五分K集中堆量):
    → 有看点，可参与
  ELSE IF (开盘直线下 AND 盘口无承接):
    → 取关，不参与
  
  关键原则: 承接决定一切，点位只是参考
}
```

### 案例2: 常山北明 - 市场共识的预期差
**时间**: 2025年2月
**决策链**:

**Day 1 (2.24)**:
- **观察**: 尾盘走华为上板
- **分析**:
  - 明牌题材，无逻辑可言
  - 炒作真空期的市场行为
  - 辨识度高（前期华为概念）
- **判断**: 这种一般只能看到1-2板就断板
- **决策**: 观察为主

**Day 2 (2.25)**:
- **观察**: 冲高回落
- **分析**: 符合预期（1-2板）
- **决策**: 继续观察

**Day 3 (2.26)**:
- **观察**: 水下震荡
- **分析**: 预期就是直接水下震荡
- **决策**: 寻找预期差机会

**Day 4 (2.27)** - **关键决策点**:
- **观察**: 情绪冰点，常山北明红盘震荡
- **分析**:
  - 市场预期是水下 → 实际红盘震荡 = 正预期差
  - 日内最低点不破开盘位置 = 强承接
  - 市场共识的合力票容易引发关注
- **判断**: 这是看点！
- **决策**: 提示"日内最低点不破，就是看点"
- **操作策略**: 切换体系可以在支撑点位附近参与

**Day 5 (2.28)** - **止损决策点**:
- **观察**: 
  - 开盘低开
  - 开盘方向向下
  - 破了2.27竞价最低点
- **分析**:
  - 开盘方向说明市场预期
  - 破昨日开盘点位 = 破位
  - 周五4000+下跌 → 容易引发踩踏
  - 市场共识的合力票，不及预期 = 100%引发踩踏
- **决策**: 立即止损，取关
- **结果**: 当天杀到跌停（验证判断）

**决策框架提炼**:
```
市场共识合力票 = {
  机会条件: (情绪冰点 AND 超预期表现 AND 日内最低点不破)
  → 正预期差，可参与
  
  止损条件: (开盘破昨日最低点 AND 市场环境恶化)
  → 100%引发踩踏，立即止损
  
  关键原则: 
  1. 成也萧何败也萧何（市场共识）
  2. 切换体系保证在支撑点附近无损取关
  3. 日内成本是最重要的止损线
}
```

合力票点位 = {

### 案例4: 澜起科技/三孚股份 - 卖飞决策（实盘）
**时间**: 2026年6月23-24日
**决策链**:

**Day 1 (6.23)**:
- **操作**: 开盘把国瓷材料底仓全卖，三孚股份回板全卖，澜起科技剩下的全卖
- **理由**: "产业逻辑价全部验证"、"反正左右都是赚钱"
- **心态**: 卖飞不卖飞已经不重要了

**当天下午**:
- **观察**: 早上科技一跳
- **情绪**: "刷自己耳光"、"草他妈"
- **反思**: "Gμ票真的要先被套住 就拿住了 而且仓位也给上去了"
- **判断**: "今天金融稳住了 那么科技剩下的就不是卖点了"
- **决策调整**: "但是也别加了 两周满仓了 休息一下了"

**Day 2 (6.24)**:
- **情绪**: "昨晚失眠一晚上 吓死我了"
- **观察**: 大族激光低开五个点
- **恐慌**: "感觉 人生 完蛋了"
- **操作**: "大族激光翻红我减了一点点"、"大族激光我先全卖了"
- **结果**: "平均两个点卖了 又卖飞了"
- **反思**: "我们还是熊市的经验太丰富了"

**决策框架提炼**:
```
实盘情绪化决策 = {
  卖出触发: (浮盈较大 AND 市场波动 AND 恐惧情绪)
  → 过早止盈，频繁卖飞
  
  问题诊断:
  1. 熊市经验 → 过度警惕风险
  2. 仓位压力 → 失眠、焦虑
  3. 情绪驱动 → 违背持股纪律
  
  自我反思:
  - "要先被套住就拿住了"（仓位压力导致拿不住浮盈）
  - "牛市做不过新手"（老手天天切换）
  - "要深刻反省一下持股了"
}
```

## 2. 决策框架总结

### 框架1: 合力票决策框架
```
合力票操作 = {
  判断资金性质: (分时堆量 AND 高换手 AND 无对敲) → 合力票
  
  进场条件:
    - 日内承接有效（分时堆量 + 盘口挂单）
    - 点位在市场共识位（如十字星低点）
    - 情绪周期适合（破局期或主升期）
  
  持有条件:
    - 日内最低点不破
    - 承接持续有效
    - 市场预期未被破坏
  
  止损条件:
    - 破昨日最低点
    - 开盘方向向下
    - 承接明显减弱
    - 市场环境恶化（引发踩踏）
}
```

### 框架2: 做盘票决策框架
```
做盘票操作 = {
  判断资金性质: (分时对敲 AND 筹码锁定 AND 低换手) → 做盘票
  
  进场条件:
    - 看不懂就不做（体系外）
    - 或者有明确主力意图
  
  风险点:
    - 盘口可以作假
    - 大单净额无参考意义
    - 主力可随时砸盘
  
  决策原则:
    - 模式外不碰
    - 无法用体系推演就取关
}
```

### 框架3: 情绪化实盘决策（反面教材）
```
情绪化决策链 = {
  触发: 市场波动 + 浮盈较大 + 仓位压力
  → 恐惧情绪 → 过早止盈 → 卖飞 → 懊悔
  
  问题根源:
  1. 熊市经验路径依赖
  2. 仓位超出心理承受能力
  3. 缺少冷静的决策环境（如路上）
  
  改进方向:
  - "先被套住就拿住了"（降低初始仓位）
  - "两周满仓了休息一下"（控制持仓周期）
  - 不在路上下重仓指令（环境纪律）
}
```

## 3. "不做"决策原则

### 原则1: 看不懂就不做
**触发条件**: 无法用体系推演次日走势
**案例**: 做盘票、模式外标的

### 原则2: 承接弱不做
**触发条件**: 开盘直线下 + 盘口无挂单
**案例**: 海南华铁2.17

### 原则3: 破位不做
**触发条件**: 破昨日最低点 + 开盘方向向下
**案例**: 常山北明2.28

### 原则4: 情绪冰点不重仓
**触发条件**: 市场情绪极弱 + 无明确主线
**决策**: 观望或小仓试错

### 原则5: 路上不下重仓指令
**触发条件**: 非冷静环境
**决策**: 等待回到完整分析环境

## 4. 决策一致性分析

### 一致的决策逻辑
1. **承接优先**: 所有合力票决策都看承接
2. **点位止损**: 破位立即止损
3. **模式边界**: 体系外坚决不碰

### 不一致的执行
1. **理性体系 vs 情绪化实盘**: 
   - 体系强调持股纪律
   - 实盘频繁卖飞
   - 原因：熊市经验 + 仓位压力

2. **牛市策略未调整**:
   - 承认"老手做不过新手"
   - 但仍在频繁切换
   - 未给出明确牛市改进方案

## 5. 决策分歧点

### 分歧1: 何时止盈
- **体系教学**: "只要价格未破坏，持有不动"（借鉴南京路彼岸）
- **实盘操作**: 浮盈较大时提前止盈
- **原因**: 仓位压力 + 熊市经验

### 分歧2: 牛市是否应该改变策略
- **自我反思**: "牛市做不过新手"、"老手天天切换"
- **但未明确**: 牛市中是否应该放弃超短改做趋势？
