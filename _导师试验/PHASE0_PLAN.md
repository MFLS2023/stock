# Phase 0：女娲生成 - 执行计划

## 目标
用女娲skill生成"南京路彼岸"的第一版人格

## 前置条件
- [x] 数据已提取（40篇文章，525 chunks，22万字）
- [x] 测试问题已准备（23个问题）
- [ ] 女娲skill已安装

## Step 1：安装女娲skill

```bash
npx skills add alchaincyf/nuwa-skill
```

或者手动安装到 Claude Code skills 目录。

## Step 2：调用女娲生成人格

在 Claude Code 中执行：

```
蒸馏一个南京路彼岸

数据来源：
- 文件：C:\Users\20577\Documents\炒股\知识库\_导师试验\data\nanjinglu_extracts.json
- 40篇公众号文章
- 主题：A股投资、产业链分析、贝叶斯思维

要求：
1. 提取3-7个核心心智模型
2. 提取5-10条决策启发式
3. 分析表达DNA（语气、结构、用词）
4. 定义反模式（明确不做的事）
5. 标注诚实边界（承认局限）

输出格式：SKILL.md（符合 Agent Skills 协议）
输出位置：_导师试验/skills/nanjinglu-bian-skill/SKILL.md
```

## Step 3：女娲的工作流程

女娲会自动执行：

1. **六路并行采集**
   - 读取所有40篇文章
   - 分析核心观点
   - 提取案例
   - 识别价值观
   - 分析表达风格
   - 查找批评者视角

2. **三重验证提炼**
   每个候选心智模型必须：
   - 跨2+个领域出现过
   - 能推断对新问题的立场
   - 有排他性（不是所有人都这么想）

3. **构建Skill**
   生成 SKILL.md，包含：
   - 心智模型
   - 决策启发式
   - 表达DNA
   - 反模式
   - 诚实边界

4. **质量验证**
   - 用3个已知问题测试
   - 用1个未知问题测试
   - 检查立场一致性

## Step 4：人工测试

用 test_questions.md 中的23个问题测试生成的 Skill：

```
/nanjinglu-bian [问题1]
/nanjinglu-bian [问题2]
...
```

记录每个回答的：
- 立场是否正确
- 是否能引用来源
- 语气是否一致
- 评分（0-5）

## Step 5：评估结果

计算保真度评分：
- ≥ 85分：A级，可以进入 Phase 1（深度优化）
- 70-84分：B级，基本可用，需要针对性优化
- 60-69分：C级，需要大幅调整
- < 60分：不合格，考虑手动提炼

## 预计时间

- Step 1：5分钟
- Step 2：女娲生成 30-60分钟（自动）
- Step 3：女娲自动完成
- Step 4：人工测试 1-2小时
- Step 5：评估 30分钟

**总计：2-4小时可得到初步结果**
